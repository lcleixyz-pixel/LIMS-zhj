交付日期：2026-07-18  
包类型：沙箱排练专用包  
对应版本：G-R14 本机受控试运行治理与云端体验部署收口版  
对应提交：`2503f15a34d3a0d079429353616d66c3a370eddc`  
对应云端体验 release：`20260718-gr14-3d07a3db`

## 1. 这个包解决什么问题

本包用于给 AI 沙箱、临时 Linux 环境或受限网络环境继续做“模拟试运行排练”。

它保留 ThinkPHP 应用源码、Composer `vendor/` 依赖快照、G-R14 交付记录、fakeclock 假时钟工具和 SQLite 降真说明，方便继续验证整季剧本、页面流程、质量记录、内审链路、管理评审、文件控制、岗位授权和模板试运行。

它不是正式生产部署包，也不是云端回滚包。

## 4. 使用边界

本包适合：

- 在 AI 沙箱里继续跑模拟试运行剧本；
- 检查 G-R14 修复后的页面和流程是否可理解；
- 验证质量管理动作是否形成记录、证据链、打印件和追溯关系；
- 通过 fakeclock 观察跨月、跨季提醒和闭环；
- 在本机 Docker 或云端 MySQL 真栈复核前筛出显性流程问题。

本包不适合：

- 直接用于正式生产部署；
- 直接替换云端体验环境；
- 把 SQLite 结果视为 MySQL 生产等价结论；
- 存入正式检测业务数据、客户资料、报告正文或员工敏感信息；
- 作为 CMA/CNAS 正式运行证据。

## 5. 建议验收口径

试运行结论建议分两级记录：

1. 沙箱排练结论：用于发现流程、页面、措辞和剧本问题；
2. 真栈复核结论：在本机 Docker 或云端 MySQL 环境确认关键判断。

如出现数据库、PDF、Chromium、定时任务或架构相关异常，应先区分“沙箱噪声”与“真实产品缺陷”，不要直接把沙箱异常等同为生产风险。
