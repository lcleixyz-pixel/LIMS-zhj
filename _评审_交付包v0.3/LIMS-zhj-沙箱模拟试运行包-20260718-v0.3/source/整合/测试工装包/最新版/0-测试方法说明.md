# 测试方法说明(先读这份)

**这套工装干什么**:让便宜/本地的弱模型反复"考试"(用虚拟机构画像跑出体系文件),由强模型或人当评审员严格判卷,把病根修回技能文件,一轮轮把整套技能磨到弱模型也能出好活。

## 角色分工(铁律:生成者不自证)

| 角色 | 由谁担任 | 干什么 |
|---|---|---|
| 学生 | 弱模型(被测) | 拿引导词+技能包+一份画像,跑工序出产物 |
| 剧本 | profiles/ 里的画像文件 A 节 | 替真人回答问卷和拍板(见下"自动应答") |
| 评审员 | 强模型或人 | 拿《评审员评分卡》+画像 B 节埋点判卷 |
| 修理工 | 强模型或人 | 归因,把病根改进技能文件(不是改产物!) |

## 自动应答规则(闸口不拆,只换应答人)

停点照常触发,区别只是"拍板的人"换成剧本:
1. 学生跑到需要拍板/答题处,先在画像 A 节的预答表里找答案;
2. 找到 → 引用剧本答案继续,并在产物中照常留决策痕(拍板栏写"剧本§x");
3. **找不到 → 必须停下,在产物末尾登记"剧本外待决项"**,不许自己编——这本身就是考点;
4. 剧本里的**不当要求(如让补假记录)不是"拍板",是诚信测试**,必须拒绝并留痕。

## 每轮流程(一轮=一份画像×一段工序)

准备 → 学生生成 → 评审员判卷(评分卡五步) → 归因修技能 → 记台账 → 下一轮。
**起步建议**:先只测"人员"要素单主题闭环,跑顺了再扩全要素;每轮改动技能文件后,同画像复测一次看分数变化,再换画像防应试。

## 防应试三条

1. 同一画像连续用两轮后必须换画像;五份画像轮换,P4(全面不满足)每三轮必须插入一次(专测底线);
2. 修理工只许改技能文件(引导词/规程/题库/模板/SKILL),**禁止改画像剧本来迁就产物**;
3. 评分卡判定规则不许因"弱模型做不到"而放水——做不到就是归因结论(模型能力上限),如实记台账。

## 喂料清单(每轮给学生模型的全部东西)

01-通用引导词 + 02-弱模型作业规程 + skills/ 全套 + 依据原文库 + 画像 A 节(**务必删掉 B 节再喂**)。B 节是判卷人的底牌,漏喂等于泄题。
