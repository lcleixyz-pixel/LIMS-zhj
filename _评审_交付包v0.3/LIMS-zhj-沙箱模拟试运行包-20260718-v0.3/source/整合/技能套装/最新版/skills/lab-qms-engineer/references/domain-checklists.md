# 领域依据清单库(domain-checklists)v1.0

**用途**:依据活水系统的"底账"。开工/换领域/评审前,由 `scripts/intake_check.py` 拿本文件的机读表对照用户依据库,输出三色报告(绿=齐/黄=缺或待核/红=疑过时、名实不符、已废止)。**本系统只核对、只提醒,不代下载**——缺什么、过时什么,一律引导用户到官方渠道自行获取上传(版权与责任边界)。

**清单维护规则**:①本清单核实基准日 2026-07-08(经 CNAS 官网现行文件清单核对);②CNAS 官网"认可规范"栏发布《实验室认可规范文件清单》PDF 并定期更新(含被代替文件对照),**每季度对照一次并更新本文件版本**;③"现行版本年"列若与官方不一致,以官方为准并回改本表。

## 提醒话术模板(三色报告随附)

- **缺件(黄)**:"依据库缺《{名称}》({代号})。请到 {渠道} 自行下载现行有效版本({现行年}版)上传后重跑自检。本系统不代为获取。"
- **疑过时(红)**:"你上传的《{文件名}》版本年为 {文件年},清单记载现行为 {现行年} 版。请到官方渠道核实并获取现行版;若官方已再次换版(比清单更新),以官方为准,并请告知以便更新清单。"
- **名实不符(红)**:"《{文件名}》文件名与内容不匹配({原因}),疑似张冠李戴或文件损坏,请核实后重新上传。"
- **已废止(红)**:"《{代号}》已被 {新代号} 代替(见 known-revocations),请获取替代文件;旧文件可留档但不得作为现行依据。"
