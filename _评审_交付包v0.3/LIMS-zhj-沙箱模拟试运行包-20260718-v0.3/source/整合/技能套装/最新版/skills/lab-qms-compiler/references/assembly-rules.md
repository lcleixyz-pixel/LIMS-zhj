# 装配规则 v1.0(assembly-rules)

## 1. 结构双规
- **手册**=按 CL01 条款号做章节骨架(4 通用/5 结构/6 资源/7 过程/8 体系,29 节号一一对应),前置 0~3 章(受控页、颁布令、概况=参数区、引用文件、术语),后置附录(程序目录/工作版说明 WV/参数登记)。评审员按条款号翻,一翻一个准。
- **汇编**=独立成册、内部 CX-01~11 分节,每节**五段式**:1 目的与范围(一句大白话)/2 职责/3 程序(P·D·C·A 四段)/4 记录(JL 编号占位)/5 支撑手册章节。

## 2. 汇流约定(防各写各的)
各程序的"不符合处置"统一汇入 CX-09;"输入管理评审"统一汇入 CX-11;文件与记录管理统一按 CX-08。此三句写进汇编卷首通用约定,各节不再自建小流程。

## 3. 铁律
- 不新增:成品每句可回链至底稿已核卡;手册不产生底稿之外的要求。
- 不脑补:提取先于拼装,盘上原文为准。
- 参数与要求分家:法规最低值(如"每场所≥2 名签字人")是要求原文,写死;机构实际值(如"现有 2 名")进概况章参数点。混写会把要求参数化——严重错误。
- 决策留人:方针/目标等决策题参数标"待画像采访拍板",不代填。

## 4. 双版本
工作版=带回链与参数标记,护城河,永久保留;发布版=strip 生成,可随时重造。语义签字在两者之间:签工作版,签完才许发布。

## 5. 典型翻车与闸口对应(实录)
- 幻觉回链:手册引用了从未立卡的 F-03 → manual_check 拦。
- 漏装:底稿 §6.1/§7.3 未进手册;引用级细漏(F-26 示例句、G-C01 出处、K-M17 双胞胎卡)→ coverage_check 拦。
- 带病发布:C3 条件块 A/B 并存即出版 → strip --check 拒发。
- 讲解性残留:附录里"[K-xx]=要求卡"字样进发布版 → WV 块摘除。
