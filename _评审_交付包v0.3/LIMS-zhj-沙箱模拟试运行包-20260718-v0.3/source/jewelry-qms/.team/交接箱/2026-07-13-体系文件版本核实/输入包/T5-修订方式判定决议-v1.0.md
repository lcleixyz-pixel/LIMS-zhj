- 输入:《定向文审问题清单-v1.1》;判据:战役卡第五节三档(阈值为拟定值 P1=10 / P2=1–2 / P3=3 / P4=3,本次拍板顺带转正)
- 性质:v0.1 为建议稿;本版登记用户拍板结果

## 一、判据逐档套算

| 档 | 触发条件 | 套算结果 |
|---|---|---|
| **A 单点修** | 硬伤 ≤10 处且全部孤立(每处波及≤2份)、无共同根因 | **不满足**:A组明文项 19 个编号(按"处"计更多),且存在 3 个共同根因 |
| **B 主题级修** | 硬伤集中于 1–2 个主题(同根因),该主题成片重写,其余健康 | **字面不满足**:根因为 3 个(>P2=2);但注意——三根因均**不需要成片重写任何一份程序** |
| **C 系统性修** | 任一:硬伤>10 且散布≥1/3 文件(37 份的 1/3≈12.3,现涉手册+约 14 份程序,✓);结构性根因≥3(恰=3,压线 ✓);单点修造成≥3 组连锁断裂(**0 证据**,各修复相互独立 ✗) | **两支压线触发** |

严格照字面 → 落 C。但属于典型"跨档存疑":①根因数恰好压 P3=3 的线,而阈值系拟定值尚未转正;②C 档第三支(连锁断裂)完全未触发;③三根因的实质工作量均为"定向手术"——单点插入(≈10 处短语级)、机械清洗(脚本可辅助)、一张职责矩阵(每处改一行批准人)——**无一册需要重构**,与 C 档"整版第五版换代"的实质含义不匹配。按战役卡"就低不就高+存疑列两档对比交拍板"办理。

## 二、两档代价对比

| 维度 | **B+ 定向修(推荐)**:第四版框架内做三个主题作业+单点批 | **C 系统性修**:提前启动第五版整版换版 |
|---|---|---|
| 作业内容 | ①引用一致性大清洗(年份/名称/编号,脚本+人工核);②职责矩阵一张表并同步约 8 份文件;③A015/G001 单点补(约 10 处)+单点批(Y14/15/17/18/20/21 等)+两处缺损补写 | 以清单 v1.1 为输入,治理演练解冻,11+ 主题按新框架重构成稿,优化池 60 条一并清 |
| 预计工期 | 约 3–4 个协作会话 + 你的逐处签字;文控走文件更改单/版次升级(约 15 份文件的换版记录,行政开销不小但机械) | 按既往演练节奏估 3–6 周协作;发布前三闸+剥离全流程 |

| 残留风险 | 优化池约 60 条(旧框架预防措施、模板残留、错字族)带病运行到第五版;需靠"更改单纪律"防止修补引入新的不一致 | 基本清零;引用规范/职责矩阵内建,不再打补丁 |
| 复发风险 | 中:第四版底子仍是拷贝拼装出身,后续换版仍需人工盯 | 低:第五版按卡片回链体系生成,机器闸可复跑 |
| 失败模式 | 修补面铺太宽变成"事实上的换版"却没有换版的质检闸 | 时间盒失控(演练膨胀前科)、内审与申请时点整体后移 |

## 三、建议

**建议定 B+(第四版内三主题定向修),第五版维持押后至一次真实内审之后复议**——理由:C 档的两个触发支均为压线/按处计数所致,其实质判断句"基于带病文件内审无意义"在本案不成立(手册通用覆盖扎实、无一册需重写);而 B+ 保住内审与 CNAS 申请的时间链。若你更看重"一次清零 60 条优化项",则选 C 并接受申请时点后移。

**阈值转正建议**(拍板顺带):P1=10、P2=1–2、P3=3、P4=3 维持原值转正;另建议在 C 档加一句限定——"结构性根因≥3 且至少一个根因需整册重写时方触发",把本案这类"三个定向手术"留在 B 侧,防止按处计数虚触发。

## 四、拍板决议(2026-07-13,用户)

1. **修订方式 = B+ 定向修**:第四版框架内执行三主题作业(引用一致性清洗 / 职责矩阵 / A015+G001 单点补)+ 单点批 + 两处源缺损补写;第五版维持押后,至一次真实内审后复议。
2. **阈值转正**:P1=10 / P2=1–2 / P3=3 / P4=3 随拍板转正;C 档限定句("结构性根因≥3 且至少一个根因需整册重写时方触发")作为建议随战役卡归档,下次战役卡修订时写入。
3. 配套已拍板:升格定案+撤 Y19(拍板①);37/37 闭合(CX-10 空号确认)。
