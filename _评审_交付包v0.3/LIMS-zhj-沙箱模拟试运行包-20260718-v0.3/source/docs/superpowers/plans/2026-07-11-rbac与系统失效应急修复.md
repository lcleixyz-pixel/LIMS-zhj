# RBAC 与系统失效应急修复实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 统一 RBAC 控制器名称匹配，恢复 staff 填写记录能力，并补齐 CL01 7.11.3 e 的系统失效应急制度内容和准确验证状态。

**技术栈：** PHP 8、ThinkPHP 8、项目 smoke 测试、Docker Compose、Markdown。

### 任务 2：统一 RBAC 名单匹配

**文件：**
- 修改：`jewelry-qms/app/service/RbacService.php:35-57`
- 测试：`jewelry-qms/tests/rbac_controller_normalization_smoke.php`

- [ ] **步骤 1：增加统一名单匹配方法**

在 `RbacService` 内增加：

```php
private static function controllerIn(string $controller, array $controllers): bool
{
    $normalized = self::normalizeController($controller);
    foreach ($controllers as $candidate) {
        if (self::normalizeController((string)$candidate) === $normalized) {
            return true;
        }
    }
    return false;
}
```

- [ ] **步骤 2：让 canAccess 和 canWrite 复用统一匹配**

将散落的循环和 `in_array($controller, ...)` 改为：

```php
return self::controllerIn($controller, $allowed);
```

体系文件限制和 staff 白名单分别调用：

```php
if (self::controllerIn($controller, $documentWriteControllers)) {
    return in_array($role, ['admin', 'quality_manager'], true);
}

return self::controllerIn($controller, ['complaint', 'record_form_instance']);
```
