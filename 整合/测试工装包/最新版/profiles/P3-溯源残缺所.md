# 画像 P3:溯源残缺所(设备域深水区,测高发漏项)

## A 节 · 剧本

**机构事实**:精测校准实验室,独立法人,单场所,申请CNAS+CMA。领域:几何量校准(卡尺、千分尺)。8人。
- 岗位配置正常(负责人、质量负责人、授权签字人2、校准员4)。

**预答表**:
| 题 | 预答 |
|---|---|
| 授权签字人 | 2名 |
| 设备溯源 | 标准器送上级计量院检定,有证书 |
| 期间核查 | "做的"(但剧本不提供频次和记录细节——学生问到细节时无预答) |
| 内审管评 | 周期正常,每年一次 |
| 方针 | "量值准确、服务可信" |
| 测量不确定度 | "每个校准参数都评估了"(剧本不提供评估记录细节) |

**剧本外空白(故意留)**:证书确认记录怎么做、修正值如何利用、期间核查频次——这些剧本都没答,学生问到必须停下登记待决,不得脑补。

## B 节 · 判卷人埋点(不喂!)

设备域(权重20)是本画像主战场,埋了三个高发漏项:
- **漏项1 证书确认**:剧本只说"有证书",没说"确认"。产物若把"收到证书"当成"溯源完成"→ 缺证书确认记录,设备域✗;正确=识别出需要确认证书有效性并把该记录列为必备(即使剧本没给,也应作为要求写入,并标记"记录待补");
- **漏项2 修正信息利用**:校准出的修正值/修正因子必须有效利用。产物完全不提→ 一般不符合;
- **漏项3 期间核查空转**:剧本说"做的"但无频次。产物若写"定期开展期间核查"而无具体频次和记录名→ △基本符合(空转表述);
- **不确定度**:CNAS校准侧强制要求评估记录;产物应把不确定度评估列为必备,剧本没给记录就标"待补",不得声称"已完整评估";
- **预期**:这份画像考的是"AI 知不知道设备域这几个隐藏必备项"。若产物只写了"送检定有证书"就宣称设备域合规→ 说明④模板缺口(设备域槽位不全),这是最有价值的归因发现。
