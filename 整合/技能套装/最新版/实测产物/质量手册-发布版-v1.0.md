# 1 前言
## 1.1 公司简介
青禾检测有限公司,独立企业法人,位于XX省XX县XX路XX号,主要从事水质检测服务。现有员工9人,设有检测室与办公室。检测人员均经培训考核合格后上岗。本机构以"公正独立、科学准确、诚信服务"为宗旨,致力于为辖区内饮用水安全提供可靠检测数据。检测领域:水质检测(pH/电导率/浊度/重金属等)。体系覆盖:CMA资质认定+CNAS实验室认可双体系。

## 1.2 公正性与保密声明
本机构以"公正独立、科学准确、诚信服务"为质量方针,管理层承诺不受任何商业、财务或其他压力损害公正性。全体人员签订保密协议,对检测活动中获知的国家秘密、商业秘密承担保密义务。

## 1.3 手册说明与文件架构
本手册是青禾检测有限公司管理体系的纲领性文件,描述本机构的质量方针与目标、组织结构与职责,概述管理体系全部要素,依据CNAS-CL01:2018、G001:2024、A007及CMA评审准则编制。本机构管理体系文件分四层:第一层质量手册(纲领);第二层程序文件(规定各质量活动的目的、范围、职责与流程);第三层作业指导书(具体操作规定);第四层质量与技术记录表格(体系运行的证据)。

# 2 质量方针与质量目标
## 2.1 质量方针
公正独立、科学准确、诚信服务

## 2.2 质量目标
本机构制定以下可测量的质量目标:
- 报告及时率≥98%(每月统计/质量负责人考核)
- 客户满意度≥95%(每半年统计/质量负责人考核)
- 检测差错率≤0.5%(每季度统计/技术负责人考核)
- 能力验证满意率100%(每年统计/技术负责人考核)

### 6.2 人员

#### 6.2.1 人员能力要求
实验室所有影响检测活动的人员应行为公正、有能力、按管理体系要求工作。实验室应将每个岗位的能力要求制定成文件,包括教育、资格、培训、技术知识、技能和经验。技术负责人具有中级及以上相关专业技术职称或同等能力;质量负责人、技术负责人、授权签字人应有任职文件,有充分证据证明其能力持续符合要求。实验室应确保人员具备其负责活动的能力以及评估偏离影响的能力。管理层应向实验室人员传达其职责和权限。

#### 6.2.2 人员管理程序
实验室应有人员管理程序并保存记录。能力监控应规定具体频次和方式。

#### 6.2.3 授权与签字
实验室应授权人员从事特定活动。授权签字人具有中级及以上职称或同等能力。本机构授权签字人2名,均覆盖水质全参数。

#### 6.2.4 劳动关系与兼职
检验检测机构应与工作人员建立劳动/录用关系。不得使用同时在两个及以上机构从业的人员(法定情形除外)。

### 6.3 设施和环境条件
实验室设施和环境条件应适合检测活动。当环境条件影响结果质量时,应监测、控制和记录环境条件。不相容活动的相邻区域应有效隔离。CNAS+CMA认证覆盖的全部场所具有完全使用权。已识别安全因素并设置必要防护设施。

### 6.4 设备
实验室应配备正确开展检测活动所需的全部设备。设备应进行校准/检定,证书信息应经确认。应建立计量溯源方案。非固定场所使用设备有附加管理要求。申请中认可范围内的设备均须纳入管理。
