# 样例说明(先读这份)

本文件夹是一个**完全虚构**的示范:"青禾检验检测有限公司"——县级小型水质检测实验室,9 人,单场所,已有 CMA 资质、拟申报 CNAS。演示"人员"这一个要素从答卷到成品的全链条。

| 样例文件 | 对应流水线哪一步 | 照抄什么 |
|---|---|---|
| 1-画像答卷摘录.md | interviewer 采访 | "评估-建议-拍板"三栏怎么留痕 |
| 2-底稿片段-人员.md | builder 构建 | K卡、句尾回链、PDCA表长什么样 |
| 3-手册片段-两版对照.md | compiler 总装 | 工作版和发布版差在哪 |
| 4-体检报告样例.md | engineer 卡六(审老文件) | 五级判定和缺口清单怎么写 |
| 5-项目总台账样例.md | engineer 中枢 | 主题状态表、版本事件日志、停点登记区的格式 |

⚠️ 三个别抄错:①内容是虚构的,**只抄格式,别抄结论**——你的人数、周期、方针必须来自你自己的拍板;②样例为省篇幅做了删节(真实底稿一个要素几十张K卡,这里只放2张);③样例引用的标准条款号仅作格式示意,写真文件时必须核对官方原文。
