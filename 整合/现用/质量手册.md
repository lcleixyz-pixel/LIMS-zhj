# **1\. 前言**

<a id="_Toc23230"></a>
# **1\.1 公司简介**

新疆中和鉴珠宝玉石质量检测研究所（有限公司），是经工商管理部门注册登记的从事珠宝玉石检测、研究及技术咨询服务，以独立法人形式承担第三方公正检测和独立财务核算的珠宝玉石检验检测机构。

本公司下设乌鲁木齐实验室与和田实验室，均为按照认可准则及检测标准规划的符合要求的实验室。且根据检测项目的要求配置了多种检测设备，共计配备珠宝玉石检验检测仪器及设备40余套，以满足各类检测业务的需求。

公司拥有并培养了一批高素质的管理人员和专业技术检测人员，现有员工10余人。其中检测人员多数取得了国家珠宝玉石质量检验师（CGC）、英国皇家珠宝鉴定师（FGA）、中国地质大学（武汉）珠宝学院（GIC）、 NGTC彩色宝石鉴定师等资质，为公正、科学、准确、高效的检测服务提供充分保障。

按照检测—研究—教育培训相结合的发展模式，理论联系实际，  “立足乌市，服务新疆，放眼全国” ，致力于解决珠宝首饰材料检测的各类问题，促进本行业合理、规范、健康发展。

# **1\.9 术语和定义**

下列术语和定义适用于本手册，主要引自GB/T 27025\-2019第3章及《检验检测机构资质认定评审准则》（2023年版）。

<a id="_Toc9783"></a>
## **1\.9\.1 检验检测机构**

依照《检验检测机构资质认定管理办法》的相关规定，依法成立，依据相关标准或者技术规范，利用仪器设备、环境设施等技术条件和专业技能，对产品或者法律法规规定的特定对象进行检验检测的专业技术组织。

<a id="_Toc29774"></a>
## **1\.9\.2 实验室**

从事下列一种或多种活动的机构：

——检测；

——校准；

——与后续检测/校准活动相关的抽样。

<a id="_Toc3013"></a>
## **1\.9\.3 资质认定**

依照《检验检测机构资质认定管理办法》的相关规定，由市场监督管理部门依照法律、行政法规规定，对向社会出具具有证明作用的数据、结果的检验检测机构的基本条件和技术能力是否符合法定要求实施的评价许可。

<a id="_Toc12374"></a>
## **1\.9\.4 资质认定评审**

依照《检验检测机构资质认定管理办法》的相关规定，由市场监管总局或者省级市场监督管理部门自行或者委托专业技术评价机构组织相关专业评审人员，对检验检测机构申请的资质认定事项是否符合资质认定条件以及相关要求所进行的技术性审查。

<a id="_Toc28979"></a>
## **1\.9\.5 投诉**

任何人员或组织向本公司就其活动或结果表达不满意，并期望得到回复的行为。

<a id="_Toc5274"></a>
## **1\.9\.6 判定规则**

当声明与规定要求的符合性时，描述如何考虑测量不确定度的规则。\(GB/T 27025\-2019 ,3\.7\)

<a id="_Toc25436"></a>
## **1\.9\.7 验证**

提供客观证据，证明给定项目满足规定要求。\(GB/T 27025\-2019 ,3\.8\)

<a id="_Toc19301"></a>
## **1\.9\.8 确认**

对规定要求满足预期用途的验证。\(GB/T 27025\-2019 ,3\.9\)

<a id="_Toc22736"></a>
## **1\.9\.9 能力验证**

依据预先制定的准则，利用实验室间比对来按照预先制定的准则评价参加者的表现。\(CNAS\-RL02:2023\)

<a id="_Toc22698"></a>
## **1\.9\.10 测量不确定度**

根据所用到的信息，表征赋予被测量值分散性的非负参数。\(JJF 1001—2011\)

## **1\.9\.11 专项监督**

按照认可规范要求，以获准认可机构行为合规性为主要检查内容开展的不定期监督评审工作。

本公司是在工商管理部门注册，依法成立的具有独立法人的检测机构，属第三方独立检测，独立对外开展业务活动，具有独立账目和独立核算，同时就本公司检测工作引起的法律责任由公司以独立法人身份承担。本公司具有明确的法律地位，对其出具的检验检测数据、结果负责，并承担法律责任。

# **5\.2 管理层**

本检测公司实行实验室主任负责制，负责主持本公司的全面工作，管理层包括实验室主任、技术负责人、质量负责人。

## **5\.2\.1 管理层职责**

## 5\.2\.1\.1 实验室主任

职责：

1. 负责按《检验检测机构资质认定评审准则》（2023年版）、 CNAS\-CL01:2018 《检测和校准实验室能力认可准则》等相关文件标准要求建立管理体系并持续改进管理体系有效性，领导制定和实施本公司质量方针和质量目标，制定本公司的发展规划和工作计划；
2. 对公正性做出承诺；
3. 全权负责各项工作及资源调配，确保管理体系所需的资源；
4. 批准质量手册、程序文件和作业指导书，根据本公司管理体系内审结果和运行效果，组织进行管理体系评审；
5. 负责贯彻满足客户要求和法定要求的重要性，以客户为中心，确保客户满意；
6. 负责设置本公司的组织架构，任命各岗位人员；
7. 负责制定相应的管理规范，确保本公司各项工作不受其他方面的影响；
8. 确保在本公司内部建立沟通的渠道，对管理体系的过程和有效性进行沟通，以便形成统一的认识，并确保将客户要求和法定要求传达到组织的相关人员；
9. 运用过程方法建立管理体系和分析风险、机遇；
10. 负责批准新的、重大的合同评审；
11. 负责批准年度内审计划和管理评审计划；
12. 落实对客户机密进行保密的资源和责任人；
13. 批准《合格供应商名册》和采购计划；
14. 批准重大的不符合工作的纠正措施；
15. 批准年度人员培训计划；
16. 批准开展新的检测项目；

5. 对技术人员的配备考核、聘任、晋级和评定职称提出建议；

# **5\.3 实验室活动范围**

本公司按照《检验检测机构资质认定评审准则》（2023年版）、 CNAS\-CL01:2018 《检测和校准实验室能力认可准则》及CNAS\-CL01\-A015:2018 《检测和校准实验室能力认可准则在珠宝玉石、贵金属检测领域的应用说明》建立质量管理体系，开展检测活动，主要的检测活动包括：各类珠宝玉石鉴定及贵金属首饰纯度的检测。

<a id="_Toc5368"></a>
# **5\.4 实验室活动场所**                                                                                         

本公司具有满足相关法律法规、标准或者技术规范要求的场所，包括：

- 乌鲁木齐实验室地址：新疆乌鲁木齐市水磨沟区昆仑路2号华凌玉器城（华凌国际汽车用品进出口中心）四楼B\-3\-03号
- 和田实验室地址：新疆和田地区和田市伊里其乡喀河社区远东国际玉街4号楼103号

本公司的各项检测活动都在固定场所内进行，且均被管理体系所覆盖，无移动的检测工作。本公司确保环境条件不会使检测结果无效，或不会对所要求的检测质量产生不良影响。本公司依据相关的规范、方法和程序要求，当影响检测结果质量情况时，监测、控制和记录环境条件。对诸如电磁干扰、湿度、供电、温度等将予以重视，使其适应于相关的技术活动要求。当环境条件危及检测的结果时，应停止检测活动。本公司对影响检测质量的区域的进入和使用加以控制，并根据其特定情况确定控制的范围。本公司将不相容活动的相邻区域进行了有效隔离。本公司采取措施确保检验检测机构的良好内务，包括实验室环境与安全，并建立了相关的程序。

11. 负责仪器设备技术档案的建立；
12. 负责编制仪器设备的维修计划，办理报废设备的鉴定、申报工作，做好备用设备的防潮防尘等保管工作；

15. 负责组织仪器设备的维修工作，并填写维修记录，保证维修质量；
16. 负责对仪器设备的供应商和外部服务单位的质量资质进行调查，建立《合格供应商名册》。

## **5\.7\.6 样品管理员职责**

2. 入库样品按类别和检验性质分为： “留样”“待检”“在检”“已检”样品，应分别放置并有明显标识；
3. 各类样品必须经过相应处理后，按有关规定保存；
4. 做好各类样品的立账工作，做到账物相符；
5. 保持样品室内环境条件符合要求，并做好防火、防盗工作；
6. 根据检验工作任务安排，认真做好样品、器具的发放和入库；
7. 超过保管期的样品应按规定处理，并履行处理手续；
8. 遵守职业道德，不得任意挪用、串换检验样品；
9. 样品丢失按责任事故处理；
10. 负责样品的接收、验收、登记；
11. 做好样品交接时的相关保密工作。

<a id="_Toc31128"></a>
## **5\.7\.7 检测员职责**

1. 在实验室主任的直接领导下开展工作，服从分配，坚守岗位，严格遵守各项规章制度和检验人员工作守则；
2. 努力学习专业技术知识，刻苦钻研技术，不断提高检验工作水平，对本岗位的检验工作质量负责；
3. 严格执行产品技术标准和检验实施细则，按时完成检验工作；
4. 按照《仪器设备的购置、验收、调试、使用、管理、维修、降级和报废制度》的要求，正确处理仪器设备的各项情况；
5. 认真填写各项检验原始记录，确保各项检验原始记录（数据）的准确性和及时性；
6. 检验人员有权向上级领导反映违反检验细则或对检验数据弄虚作假的现象，有权拒绝使用检定不合格和超过检定有效期的仪器设备；
7. 按照要求搞好检测区域内的一切事务，做到文明检验；
8. 负责对检测环境进行监控；
9. 负责提出偏离申请。

4. 对检测证书和报告具有批准权和否决权；
5. 报告签发人具有中级及以上相关专业技术职称或同等能力，并符合相关技术能力要求；
6. 有能力签发带认可标识/联合标识或声明认可状态的报告或证书，对实验室所有对外认可声明的合规性负责

# **6\.3 设施和环境条件**

<a id="_Toc10966"></a>

<a id="_Toc5190"></a>
**6\.3\.2** 根据检测工作范围、项目的要求，提供配置适宜的检测场所和办公环境，并进行合理有效的布局，防止对检测工作产生不利影响。

<a id="_Toc11946"></a>

1. 保证动力电和照明用电的供给；
2. 天平放置在稳定的、防震动的桌子上，以保证其稳定性；
3. 对与本公司相邻区域采取有效的隔离措施；
4. 本公司应有与检测范围相应的安全监控设施等；
5. 对检测结果有影响的设施和环境条件的技术要求，按检测标准和相关要求编制作业指导书；
6. 检测室在日常工作中对影响检测结果的设施和环境条件实施监测、控制，并予以记录；
7. 检测室应注意环境条件因素（诸如灰尘、电磁干扰、温度、湿度、供电和振动等）对检测技术活动的影响。当发现环境条件危及检测结果时，检测师应停止检测；
8. 实验室与办公区要保持良好的隔离，并进行标识，无关人员未经批准不得随意进入实验区域；
9. 本公司制定并实施有关安全和人员健康的文件化程序，并配备了相应的安全防护设施；
10. 本公司应配备妥善处理有害废弃物的设施并编制相应的作业指导书；
11. 检测室内加强内务管理，配置必要的消防设施，保证检测区域的整洁、安全。

<a id="_Toc23125"></a>
**6\.3\.4** 本公司的各项检测活动都在固定场所内进行，无控制之外的地点或设施。

**6\.3\.5** 当实验室发生地址搬迁或环境重大变化时，必须立即停止使用认可标识，待制定验证计划并经CNAS现场确认合格后，方可恢复使用 。

<a id="_Toc10750"></a>
**6\.3\.6** 检验检测活动涉及用电，检测样品检测前、检测中、检测后的完整和安全，因此必须树立安全第一的意识，保证安全生产，必须建立和保持相应识别风险、评估风险、风险控制的程序，对存在的安全隐患加以控制，确保检测工作场所、环境及对其有影响的周边环境安全，保证公司及客户财产的安全。

# **6\.4 设备**

<a id="_Toc22854"></a>
**6\.4\.1** 本公司对使用的仪器设备（包括软件）实施控制管理，规范设备的配置、使用至报废的各环节管理，为此制定了对设备购置、验收、运输、存放、使用和有效维护计划的《仪器设备管理程序》，以确保所用设备的正常运转和检测结果的准确性和可靠性。

<a id="_Toc17302"></a>
**6\.4\.2 仪器设备的配置**                                                                                                              

<a id="_Toc27560"></a>
6\.4\.2\.1 根据检测的范围、项目所需的方法、工作量的需求及技术指标的要求，正确配置所需的仪器设备（包括量程范围、准确度、不确定度等的选择），以满足资源的要求。

<a id="_Toc4638"></a>
6\.4\.2\.2 设备更新及购置，必要时应组织有关人员论证、设备的购置及组织验收，具体工作按《外部支持服务和供应品管理程序》和《仪器设备管理程序》规定实施。

<a id="_Toc1961"></a>
6\.4\.2\.3 设备租赁：在特殊条件下，可向其他公司或科研机构租、借设备使用，确保其过程能力符合规定要求。

<a id="_Toc23929"></a>
**6\.4\.3 仪器设备的标识**                                                                                                              

<a id="_Toc9511"></a>
6\.4\.3\.1 设备唯一性标识：设备管理员负责建立仪器设备台账，统一编号、标识，设备的编号应具有唯一性，便于追溯和识别管理状态。

<a id="_Toc28014"></a>
6\.4\.3\.2 设备状态标识：经检定/校准的仪器以三色标形式标明仪器设备的编号、检定/校准日期及有效期等，仪器设备的校准状态标识分别为“合格”“准用”“停用”三种，通常以“绿”“黄”“红”三种颜色表示。

仪器设备的状态标识内容包括：

1. 仪器设备名称；
2. 仪器设备编号（自编号）；
3. 仪器设备状态（以绿、黄、红三色区分不同状态，详见《设备管理程序》）；
4. 检定或校准/核查日期；
5. 检定或校准/核查有效期；
6. 检定或校准/核查单位。

<a id="_Toc1681"></a>
## **6\.4\.4 仪器设备的使用管理**

<a id="_Toc13686"></a>
6\.4\.4\.1 对所有影响检测结果的仪器设备应按周期检定/校准，计划组织实施（包括新购入的仪器设备），确认符合要求后，方可投入使用。对经检定/校准所得的修正因子，应确保及时更新备份（详见《实现测量可溯源程序》）。禁止对仪器设备的随意调整（包括硬件和软件的保护）致使检测结果失效。

<a id="_Toc2383"></a>
6\.4\.4\.2 对仪器设备使用的人员应经过培训，设备操作能力得到确认。对检测设备实施维护和操作应使用最新版本的作业指导书（包括说明书和使用手册等），并方便操作及相关人员使用。

<a id="_Toc15834"></a>
6\.4\.4\.3 操作者在使用设备前，应对设备进行运行状态检查，以证实其能够满足规定标准要求。

<a id="_Toc23269"></a>
6\.4\.4\.4 操作过程中发生过载或处置不当、出现可疑结果，或已显示出缺陷、超出规定限度时，应立即停止使用，及时标识、处置，防止误用。同时检查分析这些缺陷或偏离对以前检测质量的影响，执行《不符合检测工作的控制管理程序》，落实有关措施，经修复后的仪器设备须进行校准确认状态正常时，方可投入使用。

<a id="_Toc13035"></a>
6\.4\.4\.5 按《期间核查管理程序》规定要求，对不太稳定、使用频率高、漂移性较大、能力验证结果有问题、对检测数据有疑问、单纯校准不能保证在有效期内正确可靠的设备进行期间核查，以保持设备给出结果的可信度。

<a id="_Toc16342"></a>
6\.4\.4\.6 对脱离本公司直接控制租借出去的仪器设备实施控制管理，设备返还后，由有关人员对设备核查验收，以满足再次投入使用需求。

**6\.4\.5 仪器设备的维修**                                                                                                              

<a id="_Toc17089"></a>
6\.4\.5\.1 设备的维修应由专业人员进行，维修后组织验收记录。

<a id="_Toc30358"></a>
6\.4\.5\.2 设备的降级使用需经确认批准后方可使用。

<a id="_Toc7337"></a>

# **6\.5 计量溯源性**

<a id="_Toc25884"></a>
**6\.5\.1** 计量溯源性是保证检测结果一致性、准确性和有效性的重要手段。对检测结果有显著影响的检测设备，均应通过检定（校准）对其进行量值溯源，使其出具的检测结果可通过连续的比较链与国家最高计量基准相联系。本公司对标准物质溯源进行控制，确保其量值溯源到国家计量基准及国际单位制（SI）基准。

<a id="_Toc4050"></a>
**6\.5\.2** 本公司对检测结果的准确性和有效性产生影响的、溯源性要求的所有仪器设备在投入使用前均进行检定和校准，通过制定文件化的设备检定计划以及程序，来对其实施有效控制（详见《实现测量可溯源管理程序》）。

<a id="_Toc22249"></a>
**6\.5\.3 特定要求**                                                                                                                       

<a id="_Toc17130"></a>
## 6\.5\.3\.1 溯源

1. 对需溯源到（SI）基准或国家计量基准的设备按检定/校准计划，由具备资格、测量能力和溯源性的机构进行检定/校准；
2. 对无法溯源到（SI）基准或国家计量基准的设备应通过使用可靠的有证标准物质，依据可接受的校验方法来提高其检测的可靠性；
3. 对于溯源到国家/国际计量标准不可能或不适用时，可采用分步校准或通过参加适当的能力验证等提供相关的证明。

<a id="_Toc13895"></a>
## 6\.5\.3\.2 标准物质

1. 将尽可能采用有证标准物质，并确保其在有效期内使用，并对其进行期间核查；
2. 在《标准物质管理程序》中规定了对标准物质等进行妥善安全处置、运输、储存和使用，防止污染或损坏，保护其完整性。

<a id="_Toc1150"></a>
## 6\.5\.3\.3 计量确认

计量确认是为确保测量设备符合预期使用要求所需的一组操作。通过定期对测量器具的性能评价，与使用要求进行对比验证，保证测量器具符合测量管理体系的要求。计量确认包括设计和实施两个阶段，目的是确保测量设备符合预期使用要求。计量确认间隔可能是时间间隔，也可能是使用次数的间隔。

# **7\.2 方法的选择、验证和确认**

<a id="_Toc8648"></a>
## **7\.2\.1 总则**

<a id="_Toc11074"></a>
7\.2\.1\.1 本公司对开展的检测项目应选择的方法都做了明确规定，且规定的方法中亦包括了被检测物品的处置、传递、储存和准备。必要时能够得到实施不确定度的评定和数据分析统计的控制。

<a id="_Toc14593"></a>
7\.2\.1\.2 本公司对开展的检测项目的主要仪器设备，均提供设备使用操作规程；对检测样品的处置亦提供作业指导书，其原则是不降低检测结果的质量。

<a id="_Toc1327"></a>
7\.2\.1\.3 如选择新的检测方法，检测室主任应组织编制相应的作业指导书或操作规程。

<a id="_Toc9362"></a>
7\.2\.1\.4 检测人员所使用的程序文件、规范、标准、作业指导书及其他应用技术文件均保存在作业现场，以便使用人员方便取阅，且保存和使用的规范标准和规程、作业指导书均为现行最新有效版本。

<a id="_Toc19984"></a>
## **7\.2\.2 方法的选择**

<a id="_Toc16468"></a>
7\.2\.2\.1 检测方法的选择将遵循符合国家规范、行业规定、地方标准的前提下，使用标准的最新有效版本，最大限度地满足客户的要求。应优先使用标准方法，使用前应进行验证。

<a id="_Toc19515"></a>
7\.2\.2\.2 当客户未对检测项目指定方法时，本公司选择方法的原则是：

1. 优先使用国际、区域或国家、行业颁布的标准方法；
2. 由著名的技术组织或有关科学书籍和期刊公布的方法，以及仪器设备制造商指定的方法（如技术说明书等）。

<a id="_Toc13214"></a>
7\.2\.2\.3 为使检测活动能够顺利进行，并保证结果的可信度，在开展检测活动之前，应验证标准方法是否能够正确地运用，以确保实现所需方法的性能和数据的有效性。具体确认方法执行《检测方法的选择与确认程序》。

标准方法及验证：

1. 标准方法在初次使用前，检测室应验证正确地运用这些标准方法，验证后经技术负责人批准后方可使用；
2. 如果标准方法发生了变化，检测室应重新验证、批准，验证的方法见《检测方法的选择与确认程序》。

<a id="_Toc673"></a>
7\.2\.2\.4 当客户提出的方法不适合或已过期时，应及时通知客户进行协商，另行选择方法。

<a id="_Toc21188"></a>
7\.2\.2\.5 对检测方法的偏离，则应提出允许偏离的申请，阐明偏离的原因和理由，经过评审和批准形成文件，并征得客户认可后，方能允许使用（见《允许方法偏离控制程序》）。

<a id="_Toc1218"></a>
## **7\.2\.3 本公司制定的方法**

为了适应长远的检测工作需要，本公司如果制定新的检测方法，则应进行可行性论证和立项，有计划、有步骤组织具有足够资源支配权且有资格的人员进行方法的制定和实施，应按照本手册的7\.2\.4和7\.2\.5的要求进行评审、验证和确认活动。本公司目前没有自己制定的检测方法。

<a id="_Toc14788"></a>
## **7\.2\.4 非标准方法**

当在标准方法中无适用方法可供选择，而必须选择非标准方法时，本公司将与客户沟通协商，让客户充分了解检测中的各环节，说明其方法经确认是有效的，征得其同意，使出具的结果能为客户所接受。选择的非标准方法在使用前应得到技术负责人适当的确认。本公司目前所使用的检测方法均为标准方法。

<a id="_Toc25404"></a>
## **7\.2\.5 方法的确认**

<a id="_Toc20749"></a>
7\.2\.5\.1 方法确认的范围包括：非标准方法、本公司自行制定的方法、超出其覆盖范围使用的标准方法、扩充和修改过的标准方法。

<a id="_Toc15841"></a>
7\.2\.5\.2 方法的确认过程包括：

1. 预期用途的识别（包括被确认方法应满足具体预期用途的特定要求和必须满足的客户需求）；
2. 采用合适的确认技术，确定被确认方法的特征（指使用所确认的得到的值的范围和准确度）；
3. 评价使用确认得到的值的范围和准确度是否满足预期用途；
4. 核查所确认的方法的有效性声明。

<a id="_Toc13761"></a>
7\.2\.5\.3 方法的确认是通过核查方式，并提供客观证据，以证实某一特定预期用途的特殊要求得到满足。用于确定某方法性能的技术是下列情况之一，或是其组合：

1. 使用参考标准或标准物质（参考物质）进行校准或评估偏倚和精密度；
2. 对影响结果的因素做系统评审；
3. 与其他方法所得的结果进行比较；
4. 实验室间比对；
5. 根据对方法的理论原理和实践经验的科学理解，对所得结果不确定度进行的评定。

<a id="_Toc12154"></a>
7\.2\.5\.4 本公司对选择的上述方法进行确认，其目的是经过确认来证实该方法是适用和有效的，同时，确认的方法将包括尽可能多的检测专业领域。

<a id="_Toc2288"></a>
7\.2\.5\.5 本公司对方法的确认制定了《检测方法的选择与确认程序》，该程序规定了应做的确认结果的记录。在程序中对确认可采用的技术进行了描述。

# **7\.3 抽样**

<a id="_Toc14924"></a>
## **7\.3\.1 总则**

抽样是检测工作的前道工序，正确的、科学的、合理的抽样方法可确保抽样的真实性和代表性，提高检测工作的准确性和有效性，减少检测风险。策划和控制抽样过程，保证抽样的科学性、代表性、随机性、可追溯性。在珠宝检测过程中，一般不进行抽样工作，对客户所送检的样品都要全部进行检测，若需要抽样时，实施对抽样过程必须控制的因素，对抽样计划的制定，抽样采用的统计方法，抽样实施，抽样记录和允许偏离的处置等作出明确规定。

<a id="_Toc31531"></a>
## **7\.3\.2 抽样计划和抽样方案**

按有关检测标准、规范或合同中对抽样的项目、地点、位置、时间、频次、方法、样本数量和判定准则的规定执行。如果专业标准或规范中没有关于抽样的具体规定，则要根据适当的统计方法制定抽样计划和抽样方案（如根据国家抽样标准），并满足客户及相关方的要求。当客户对文件规定的抽样程序有偏离、添加或删节的要求时，业务部在《检测委托合同》签订时（或抽样过程中）记录这些要求和相关的抽样资料，并记入包含检测结果的所有文件中，同时告知相关人员。

<a id="_Toc5656"></a>
**7\.3\.3**当客户对文件规定的抽样程序有偏离、添加或删节的要求时，需详细记录这些要求和相关的抽样资料，并被纳入包含检测结果的所有文件中，同时告知相关人员。

<a id="_Toc31714"></a>
**7\.3\.4**当抽样作为检测工作的一部分时，记录与抽样有关的资料和操作，这些记录需包括：所用的抽样方法、抽样日期和时间、样品名称、抽样人签字、所用设备名称和型号、抽样项目、地点、位置、环境或运输条件（如果相关）、样品数量、判定准则、样品外观描述、必要时标明抽样地点位置示意图等，还可以通过相片、录像等显示。

<a id="_Toc31039"></a>
**7\.3\.5** 本公司不从事送检产品的抽样活动，本公司在检测报告中明确声明检测结果仅对来样负责。

**7\.4\.2** 本公司建立了样品标识系统，任何样品都必须按此系统进行编号，并且确保样品编号的唯一性，且应与检验报告或鉴定证书有一一对应关系。该系统的启动可确保样品唯一标识保持检测全过程（包括实物和记录），本公司的样品编号规则为：

公司代码Z\+年份后两位数字\+月份\+5位数字编码，例如乌鲁木齐2018年5月份编号为Z200500001～Z200599999。

<a id="_Toc19957"></a>
**7\.4\.3** 样品的标识确保不会在实物及记录和其他文件中混淆，具有唯一性以实现追溯，必要时标明其“待检”“在检”“完检”“留样”的状态。同时对群组样品进行必要的标识细分。

<a id="_Toc1426"></a>
**7\.4\.4** 在样品的交接过程中，实验室应对样品的特征予以详细地记录并得到双方的确认。在样品接收、移交过程中，如发现样品异常、与规定条件的偏离、样品与委托内容不符、委托要求不明确或不详尽、对样品的适用性持有怀疑时，应及时记录，并向委托方提出，取得进一步明确的说明，形成文件，并由委托方确认。当客户知道偏离了规定条件仍要求进行检测时，实验室应在报告中作出免责声明，并指出偏离可能影响的结果。

<a id="_Toc22642"></a>
**7\.4\.5** 样品流转过程中，有关人员应检查确认样品标识，接收者应遵守样品的使用说明，对样品加以保护，避免非正常损坏或丢失。

<a id="_Toc15130"></a>
**7\.4\.6** 样品的保管应具备适当的设施和环境条件及安全措施，应分类定位存放，以防止样品损坏、丢失和混淆的发生，保证其安全防护要求的实现，保证样品状态的完好；当样品需要存放在规定的环境条件下存放时，按其规定进行维  持、监控和记录这些条件。

<a id="_Toc26612"></a>
**7\.4\.7** 完成检测的样品由检测人员交还给样品管理员。如样品无需退还给客户时，由样品管理员清理出现场。

<a id="_Toc28385"></a>
**7\.4\.8** 按《保护客户机密信息程序》的规定和委托要求，对客户的样品和有关资料信息予以保密，必要时，制定相应的保密措施控制实施。

<a id="_Toc19935"></a>
**7\.4\.9** 实验室应有严格的保安措施，尽量缩短高价值样品的检验和保存时间。

# **7\.6 测量不确定度的评定**

<a id="_Toc1897"></a>
**7\.6\.1** 本公司将依据有关标准和政策的要求，编制评定测量不确定度的程序。详见《测量不确定度的评定管理程序》。

<a id="_Toc24448"></a>
**7\.6\.2** 技术负责人根据《测量不确定度的评定管理程序》，组织检测部及相关项目检测人员实施测量不确定度的评定。

<a id="_Toc8501"></a>
**7\.6\.3** 本公司将对需要评定测量不确定度的检测项目逐步建立并实施适合该项目的测量不确定度的评定方法，并在以下情况出现时，在检测报告中给出测量结果的不确定度：

1. 当测量不确定度与检测结果的有效性或应用有关；
2. 客户要求给出不确定度；
3. 不确定度影响检测结果与规定指标的符合性判断；
4. 仪器设备校准结果。

<a id="_Toc24794"></a>
**7\.6\.4** 影响测量不确定度的因素：

1. 人员操作的不一致性；
2. 仪器设备的不精密、不准确性；
3. 试剂和消耗材料的不均匀、不稳定性；
4. 检测方法的缺陷；
5. 环境条件的变动；
6. 测量溯源造成的误差；
7. 抽样的代表性和随机性不足；
8. 样品不均匀、不稳定。

以上这些影响因素在评定时需全面考虑，不应遗漏也不要重复。

<a id="_Toc9923"></a>
**7\.6\.5** 为作出合理的评定，在评定测量不确定度时，需对给定条件下的所有重要不确定度分量，采用适当的分析方法考虑所有显著贡献，包括来自抽样的贡献。

<a id="_Toc31395"></a>
**7\.6\.6** 若某些公认的检测方法规定了测量不确定度主要来源的极限值和计算结果的表达形式时，本公司只要遵守检测方法和报告要求，可直接引用该不确定度。

<a id="_Toc26667"></a>
**7\.6\.7** 在需要评定测量结果的不确定度时，应考虑各因素等不确定度分量对合成不确定度的作用。

<a id="_Toc30474"></a>
**7\.6\.8** 开展检测的实验室应评定测量不确定度。当由于检测方法的原因难以严格评定测量不确定度时，实验室应基于对理论原理的理解或使用该方法的实践经验进行评估。

<a id="_Toc19254"></a>
## **7\.6\.9 评定依据：**

1. ISO/IEC 17025:2017 《检测和校准实验室能力通用要求》；
2. 《检验检测机构资质认定评审准则》（2023年版）；
3. CNAS\-CL01\-G003:2018《测量不确定度的要求》。

# **7\.7 确保结果有效性**

<a id="_Toc4138"></a>
**7\.7\.1** 本公司应对所开展的检测项目的检测结果的质量进行有效性控制，开展有计划和有系统的质量保证活动，保证检测结果的准确性、可靠性，提高客户对本公司的信任。

<a id="_Toc27917"></a>
**7\.7\.2** 本公司制定了《检测结果质量控制及能力验证程序》，程序中规定了一系列质量控制活动，确定了监控计划的编制、实施要求和内容。

<a id="_Toc15327"></a>
**7\.7\.3** 在检测活动中，在可行的情况下采用适合的统计技术使检测的质量发展趋势得到及时了解，以便发现异常波动，采取预防措施加以控制。

<a id="_Toc5803"></a>
**7\.7\.4** 监控活动将有计划性地实施，并对其计划内容、监控措施进行定期的评审，以适当调整计划内容，保证计划实施的有效性。

<a id="_Toc2416"></a>
**7\.7\.5** 本公司应根据有证标准物质的来源情况、检测的特性和范围以及实验室人员的多少来制定内部质量控制计划，该计划包括可疑结果的判断准则。适当时，内部质量控制计划所采用的技术可包括但不限于：

1. 使用标准物质或质量控制物质；
2. 使用其他已校准能够提供可溯源结果的仪器；
3. 测量和检测设备的功能核查；
4. 适用时，使用核查或工作标准，并制作控制图；
5. 测量设备的期间核查；
6. 使用相同或不同方法重复检测；
7. 保存样品的重复检测；
8. 物品不同特性结果之间的相关性；
9. 审查报告的结果；
10. 实验室内比对；
11. 盲样测试。

# **7\.8 报告结果**

<a id="_Toc24112"></a>
**7\.8\.1** 检验检测报告（证书）是本公司提供给客户的最终产品，也是检验检测工作的最终体现。本公司为保证客观、准确、清晰、完整地出具检测报告，且保证所编制的检测报告包含足够信息满足客户、检测方法和说明检测结果所必需的要求，制定了《结果报告管理程序》使结果报告得到有效控制。

<a id="_Toc10768"></a>
## **7\.8\.2 报告或证书的通用要求**                                                                                                   

<a id="_Toc7767"></a>
7\.8\.2\.1 对检测业务范围内的各专业领域的检测结果以检测报告、证书或标签的统一规范格式，准确、清晰、明确和客观地提供给客户，且满足检测方法的要求及客户要求。

<a id="_Toc30332"></a>
7\.8\.2\.2 提供的检测报告一般包括标准规范、规程、客户要求、检测方法规定和说明检测结果所必需的信息。必要时，应对有效期进行说明。

<a id="_Toc22801"></a>
7\.8\.2\.3 根据协议、合同及有关资料管理规程的要求，可为客户提供简化方式的检测报告（包括内部信息的提供），其按规定要求的全部信息均可在本公司的存档资料中查阅或获取。

<a id="_Toc4728"></a>
7\.8\.2\.4 对报告中的所有信息负责，客户提供的信息除外。客户提供的数据应予以明确标识。此外，当客户提供的信息可能影响结果的有效性时，报告中应有免责声明。当实验室不负责抽样（如样品由客户提供），应在报告中声明结果仅适用于收到的样品。

<a id="_Toc7228"></a>
7\.8\.2\.5 如果检测报告中包括从分包方获得的检测结果，应清晰地标明。

<a id="_Toc4276"></a>
## **7\.8\.3 检测报告或证书的基本要求及内容**

<a id="_Toc8944"></a>
## 7\.8\.3\.1 基本要求：

1. 数据准确可靠，表述明确易懂，结论客观公正，标识清晰完整；
2. 采用法定计量单位和标准化语言，数据有效位数正确；
3. 报告内容与原始数据、任务单、委托单、样品接收单等有关内容保持一致；
4. 正确使用认证/认可标识。

<a id="_Toc28293"></a>
## 7\.8\.3\.2 基本内容：

1. 标题，如《检验报告》；
2. 标注资质认定标志，加盖检验检测专用章（适用时）；
3. 本公司的全称、本公司所在地址，进行检测的地点或客户设施（如与本公司地址不同）；
4. 唯一性标识：在检测报告的每一页上注明编号，作为检测报告唯一标识，同时，标明总页数和分页码，以识别各页本身的唯一性及与检测报告的整体关系，可用“以下空白”字样来标识检测报告的结束；
5. 委托单位名称、联络信息、项目名称；
6. 所用方法的标识：给出采用的标准、规程或其他需说明的检测依据及协议检测文件的编号及名称；对方法的补充、偏离或删减；
7. 检验检测样品的描述、状态和标识；
8. 检验检测的日期；
9. 检测结果：给出检测的数据、导出的结论（包括测量单位）；
10. 对检验检测结果的有效性或应用有影响时，提供检验检测机构或其他机构所用的抽样计划和程序的说明；
11. 检验检测报告或证书签发人的姓名、签字或等效的标识和签发日期；
12. 检验检测结果的测量单位（适用时）；
13. 实验室应做出未经批准，不得复制（全文复制除外）报告或证书的声明。

## **7\.10\.1 不符合检测工作的控制**

<a id="_Toc28604"></a>
7\.10\.1\.1 为保证检测结果的准确性，实施对检测工作中出现的不符合进行控制，以防止非预期的检测结果出现，使不符合检测工作得到及时妥善地处理，本公司制定了《不符合检测工作管理程序》，防止不合格报告的发放或使用。

<a id="_Toc25848"></a>

<a id="_Toc22905"></a>
7\.10\.1\.3 对发生的不符合检测工作应根据其性质和严重程度由质量负责人作出评价，提出处理意见，对不符合的可接受程度作出决定，并明确采取纠正措施的要求。

<a id="_Toc20998"></a>
7\.10\.1\.4 经评定暂时无法通过纠正措施恢复正常的检测活动，应决定取消相关检测工作，并及时通知客户。

<a id="_Toc11804"></a>
7\.10\.1\.5 当责任部门对不符合检测工作采取的整改措施经验证其有效后，由质量负责人批准检测工作的恢复。

<a id="_Toc12502"></a>
7\.10\.1\.6 经评定表明不符合检测工作对本公司的体系运行和程序的符合性产生怀疑或该不符合检测工作可能再度发生时，应制定和实施纠正措施，按《实施纠正措施程序》有关要求执行。

<a id="_Toc27432"></a>
7\.10\.1\.7 对不符合检测工作采取的措施及过程应形成记录，并予以保存。

# **8\.1 管理体系文件**

<a id="_Toc23478"></a>
## **8\.1\.1 管理体系的建立**

<a id="_Toc280"></a>
8\.1\.1\.1 本公司最高管理者为实验室主任，实验室主任主持建立与本公司业务、检测活动范围、工作内容相适应的管理体系，制定本公司的质量方针和总体目标，并配置相应的资源，使管理体系实施运行，并不断寻求改进，以便保持管理体系的有效性。

<a id="_Toc26773"></a>
8\.1\.1\.2 质量方针和总体目标应体现实验室的能力、公正性和一致运作。总体目标应在管理评审时加以评审。

<a id="_Toc28516"></a>
8\.1\.1\.3 质量负责人依据《检验检测机构资质认定评审准则》（2023年版）标准的要求和本公司的质量方针，组织有关各方和人员建立文件化的管理体系。

<a id="_Toc5780"></a>
8\.1\.1\.4 本公司管理体系建立方式

依据CNAS\-CL01:2018第8\.1条和GB/T 27025\-2019第8\.1条，实验室可选择下列两种方式之一建立管理体系：

**方式A：** 管理体系满足CNAS\-CL01:2018（IDT\. GB/T 27025\-2019）第4章至第8章的要求，本管理体系文件直接体现上述各条款的要求，且满足CNAS\-CL01\-G001:2024的应用要求；

**方式B：** 按照ISO 9001要求建立和维护管理体系，并能证明该管理体系支持并符合CNAS\-CL01:2018第4章至第8章的要求。

本公司选择并采用方式A建立管理体系，理由如下：

1. 方式A更直接体现检测实验室管理体系的特殊要求，管理文件结构与CNAS\-CL01:2018条款一一对应，便于评审和审核时逐条核查；
2. 方式A的管理文件可直接引用CNAS\-CL01:2018和GB/T 27025\-2019的条款要求，无需额外的符合性映射工作；
3. 本公司建立和运行的质量手册、程序文件、作业指导书、记录表格四层文件体系，已完整覆盖CNAS\-CL01:2018第4章至第8章的全部要求；
4. 本公司同时满足《检验检测机构资质认定评审准则》（2023年版）的要求，管理体系与评审准则条款的对应关系详见附录15《质量手册条款对照表》。

<a id="_Toc21466"></a>
## **8\.1\.2 管理体系的文件构成**

本公司管理体系文件的构成分为四层，包括质量手册、程序文件、作业指导书、质量和技术记录，确保检测结果达到要求的质量程度。各层文件共同构成完整的管理体系，相互支持，协调运行。

第一层：《质量手册》（XZTC/SC）——是本公司管理体系运行的纲领性文件，阐述本公司质量方针、目标和管理体系各要素的要求，描述管理体系结构和文件架构，直接对应CNAS\-CL01:2018第4章至第8章的条款要求。

第二层：《程序文件》（XZTC/CX）——是《质量手册》的支持性文件，共计35个程序，对管理体系运行中各项重要的质量和技术活动的流程、职责分工和操作要求进行详细描述，详见附录14《程序文件目录》。

第三层：《作业指导书》 ——是各种管理工作和检测工作的操作文件，规定了各项检测活动的具体操作步骤、方法、仪器操作规程等技术性文件。

第四层：质量记录和技术记录——是管理体系各项活动的客观证据。质量记录包括内审记录、管理评审记录、纠正措施记录等；技术记录包括检测原始记录、设备检定校准记录、样品流转记录、人员培训记录等，检验检测原始记录和报告保存期限不少于6年。

# **8\.3 管理体系文件控制**

<a id="_Toc30233"></a>
## **8\.3\.1 管理体系文件的构成和形式**

<a id="_Toc19790"></a>
8\.3\.1\.1 根据文件的来源，文件可分成内部文件和外来文件：

1. 内部文件：本公司制定编写发布的各种文件，如质量手册、程序文件、作业指导书、各种工作计划和原始记录等；
2. 外部文件：与本公司管理和检测活动有关的法律法规、规章制度、标准、检测方法、指导书等。

<a id="_Toc31488"></a>
8\.3\.1\.2 本公司的所有文件可以是纸张、电子媒体、拷贝文件等形式。

<a id="_Toc14183"></a>
## **8\.3\.2 文件的批准和发布**

<a id="_Toc21357"></a>
8\.3\.2\.1 凡作为管理体系组成部分发给本公司人员的所有文件，在下发之前必须得到质量负责人/技术负责人的审核，实验室主任的批准，办公室资料管理员负责建立所有受控文件清单，并进行文件的发放。文件分发时应有发放记录，便于查阅，以防止使用无效和作废文件。

<a id="_Toc26269"></a>
8\.3\.2\.2 本公司制定《管理体系文件控制和维护程序》应确保：

1. 本公司所有人员与部门得到相应文件是最新有效版本，方便使用；
2. 由质量负责人在每年管理评审前组织公司管理人员对管理体系文件进行审查，以确保文件的有效性和符合性，必要时组织进行修订，以保证持续适用和满足使用的要求；
3. 文件修订后资料员应及时从所有使用和发布处撤出无效和作废文件，对作废文件加盖“作废”标记，防止使用无效文件；
4. 对于存档保留的过期作废文件，应在文件封面上做出 “作废保留”标识；超过保存期的“作废保留”文件，呈报质量负责人批准后销毁。

<a id="_Toc9846"></a>
8\.3\.2\.3 本公司制定发布的管理体系文件均应有唯一性标识，标识内容可包括：文件的名称、编号、修订状态、页码、总页数和发布日期的名称及发放编号。

<a id="_Toc11549"></a>
## **8\.3\.3 文件变更**

<a id="_Toc28481"></a>
8\.3\.3\.1 本公司管理体系文件需要变更时，先由相关人员提出变更申请，变更申请应由原审查责任人进行审查，由原批准人进行批准，变更申请人应在变更申请中说明变更原因，以确保审查和批准人员能得到相应的背景资料。

<a id="_Toc27770"></a>
8\.3\.3\.2 本公司文件允许授权手写划改（不允许擦涂），须注明修改日期、批准人及修改人签名等信息。

<a id="_Toc6158"></a>
8\.3\.3\.3 换版、修订的文件应尽快正式发布，让文件使用人知道和理解。

<a id="_Toc8456"></a>
8\.3\.3\.4 资料管理员应及时从所有使用和发布处撤出无效和作废文件，对作废文件加盖“作废文件”标记，防止使用无效文件。

<a id="_Toc17068"></a>
8\.3\.3\.5 文件修订后，对于修订的内容，资料管理员必须在《文件修订页》上注明。

<a id="_Toc18679"></a>
8\.3\.3\.6 本公司情况变化或文件在执行过程中发现下列问题应及时修订：

1. 国家颁布新的质量政策和法规，手册中有关内容与新颁布的法律法规有矛盾；
2. 组织机构局部变化，或关键岗位人员变动；
3. 管理体系运行时发现手册有不完善的地方，需要纠正或改进；
4. 客户投诉时或内审时发现问题，采取纠正措施时涉及质量手册中的条款，需要调整；
5. 检测项目、方法、环境、设备、人员技能等发生较大变化，需要修改某些章节条款时；
6. 其他需修改的情况；
7. 质量手册修订后由质量负责人审核，公司实验室主任批准。

<a id="_Toc20900"></a>
## 8\.3\.3\.7 文件改版

本质量手册在有以下情况之一时，需对手册改版：

1. 一次修改文件的数量较大，修订内容超过了三分之一；
2. 组织机构发生重大变化；
3. 服务能力发生重大变化；
4. 质量方针和质量目标改变；
5. 评审标准改变；
6. 评审时管理体系出现较大问题。

# **8\.4 记录控制**

<a id="_Toc1185"></a>
## **8\.4\.1 总则**

<a id="_Toc32415"></a>
8\.4\.1\.1 记录是为完成的活动或达到的结果提供客观证据的活动过程，形成的文件也是质量活动的证明文件，记录可以表明质量要求得到满足的程序，同时也为管理体系要素运行的有效性和质量活动可追溯性提供客观证据，以实现管理体系的持续改进。本公司制定了《记录控制程序》，其中对记录的识别、收集、索引、存档、存放、维护等环节作出了明确的规定。

本公司的记录分为质量记录和技术记录，质量记录包括来自内部审核和管理评审的报告及纠正和预防措施的记录。

<a id="_Toc24769"></a>
8\.4\.1\.2 本公司所有的记录格式应规范化、信息足够，各岗位人员填写的记录应清晰明了，并有唯一性编号，便于管理，记录的保存应由资料管理员负责并保存在具有防止损害、变质、丢失等适宜的环境设施中。观察结果、数据和计算结果，必须在当时予以记录，并按特定任务分类识别。

<a id="_Toc10170"></a>
8\.4\.1\.3 记录编制和审批：由质量负责人负责组织质量记录格式的编制和审批，技术负责人负责组织技术记录格式的编制和审批，确保记录中包含满足记录要求的足够信息。办公室负责记录的控制和内部审核、管理评审记录的保存，以及记录格式的备案和印制。

<a id="_Toc12712"></a>
8\.4\.1\.4 记录的形式：可以纸张、电子媒介、硬盘拷贝、计算机检测管理软件等形式保存。

<a id="_Toc17026"></a>
8\.4\.1\.5 保密要求：公司应对工作人员规定保密要求，对进入记录的存放场所进行控制，备份以电子形式存储的记录，对贮存在计算机中的记录采取设置密码等措施，防止非法侵入和修改。

<a id="_Toc25205"></a>
## 8\.4\.1\.6 记录的更改：

1. 技术记录的更改，只能由原始记录人采用划改（不允许擦涂），同时在其右上方填写正确内容，对记录的所有改动应有改动人的签名或盖章；
2. 对以电子形式存储的记录，同样按上述措施要求进行更改（如加密、设置只读方式等）并及时备份，防止原始数据的丢失或改动，确保只有经授权的人员才能查阅、修改。

<a id="_Toc12231"></a>
## 8\.4\.1\.7 保存期限

各类记录根据其重要性规定适当的保存期限进行保存管理，记录保存期限应符合合同义务，本公司的检验检测原始记录和报告至少保存6年。如果法律法规、专业领域认可或认证要求文件或客户规定了更长的保存期要求，本公司应满足这些要求。

人员或设备记录应随同人员工作期间或设备使用时限全程保留，在人员调离或设备停止使用后，人员或设备技术记录应再保存6年。

技术记录，无论是电子记录还是纸面记录，应包括从样品的接收到出具检测报告过程中观察到的信息和原始数据，并全程确保样品与检测报告的对应性。

# **8\.7 纠正措施**

<a id="_Toc8592"></a>
**8\.7\.1** 纠正措施是本公司实施有效质量管理和质量风险控制必不可少的手段之一，本公司制定了《实施纠正措施程序》，规定了相应人员的职责和权利，对本公司工作中存在并已确认的不符合工作、偏离管理体系或技术运作中的政策和程序的活动立即实施纠正措施。

<a id="_Toc15956"></a>
## **8\.7\.2 原因分析**

实施纠正措施的负责人、责任部门或岗位调查分析产生问题的原因。原因分析要从确定问题的根本原因开始，确定问题的根本原因需认真分析产生问题的所有环节，确定主要因素。原因可能包括：客户的要求、样品及规格、方法和程序、人员的技能和培训、供应品的质量、仪器设备及校准等。

<a id="_Toc19452"></a>
## **8\.7\.3 纠正措施的选择和实施**

<a id="_Toc7513"></a>
8\.7\.3\.1 纠正措施的采取应根据不符合工作的控制、内/外部审核、管理评审、客户反馈、员工的观察、实验室间比对及能力验证等管理体系和技术运作中的问题来加以确定。必要时，更新在策划期间确定的风险和机遇。

<a id="_Toc1973"></a>
8\.7\.3\.2 针对产生不符合的原因、部门、岗位，制定与选择最大程度地消除其原因、防止其再发生的纠正措施；纠正措施应切实有效，应与问题严重程度相适应，权衡风险、利益和成本。由纠正措施而导致的任何变更，应制定成文件并加以实施。

<a id="_Toc1274"></a>
8\.7\.3\.3 纠正措施计划需经质量负责人/技术负责人评价和批准，以确保其适宜有效。

<a id="_Toc4365"></a>
## **8\.7\.4 纠正措施的监控**

本公司管理层、监督员、内审员应对纠正措施实施结果进行监控和记录，以确保所采取的纠正措施是适时的、有效的。资料员保存纠正措施的原因分析、制定、实施和验证的有关记录。

# **8\.9 管理评审**

<a id="_Toc8307"></a>
**8\.9\.1** 管理评审是本公司的管理层对管理体系运行的适应性和有效性进行正式评价，实验室主任主持本公司的管理评审，质量负责人负责制定每年度的管理计划。管理评审的周期为12个月，但可根据实际运行状况增加临时评审。本公司执行的管理层应根据预定的日程表和程序对管理体系和检测活动进行评审，以确保其持续适用和有效，并对管理体系进行必要的改动或改进。评审工作的实施执行《管理评审程序》。

<a id="_Toc13189"></a>
**8\.9\.2** 管理评审的输入应包括以下相关信息：

# **附录6：《员工行为规范》**

**一、为维护本公司的公正、诚实的立场，保持检测活动的独立性，特向社会发布如下声明：**

1. 遵守国家法律法规和认可机构的要求，对公司内部开展公正检测服务，履行法律义务，承担法律责任；
2. 树立良好的执业行为，保持并发展认可的检测能力和有效的管理体系；
3. 坚持公开、公正、自愿申请和强制管理相结合的无歧视检测服务原则；
4. 维护客户的权利，保护客户的所有权和专利权不受侵犯；
5. 坚持独立检测、独立判断，检测活动不受任何公司其他部门的影响；
6. 不接受有违检测公正性的投资和赞助，不介入客户之间的市场竞争和利益冲突，以上声明表明了本实验室的公正立场，望全体员工严格遵守。

**二、保证公正性、诚实性和独立性政策和措施**

1. 不利用职务的便利谋取不正当的经济利益，承诺对客户应履行的法律义务和承担的民事责任；
2. 当检测工作与其他工作发生冲突时，应本着服从检测工作的原则，避免给员工造成心理上的压力；
3. 当工作人员感受到来自内部或外部压力时，应分析原因并及时制定相应的政策，以减少不合理原因给员工造成的各种压力；
4. 坚持公开、合理的收费，不暗示客户接受任何不合理的附加要求；
5. 不阻拦客户与检测有关的申诉和投诉，承诺对每一起申诉都将在约定的时间内做出合理的答复；
6. 本公司要求全体员工严格遵守并认真、按时履行与客户签订的一切协议或合同，承诺绝不延误客户的经济利益；
7. 本公司承诺如实告知客户有关本公司的检测能力、服务费用、应承担的责任与应履行的义务、真实的检测过程和结果，以及客户的权利，维护客户对本公司服务的知情权。
8. 本公司将检测人员的行为和业绩纳入员工考核范围，对违反本公司行为准则的人员，视情节轻重和所造成的后果，将分别给予批评、警告、经济或/和行政的处罚，对于触犯法律的，则追究其法律责任。
9. 本公司承诺全体员工都应忠于本公司的公正性和诚实性，始终遵守行为规范。

**三、维护客户的权利**

1. 本公司检测服务提出符合自己要求的权利；
2. 对检测服务提出保护机密信息和所有权的要求；
3. 对提供的检测服务有详细了解细节的知情权；
4. 对提供的检测数据和结果有疑问质询权；
5. 在不妨碍其他客户和确保安全的前提下可对本公司的检测实施监督与核查权；
6. 对提供的检测样品及其技术、专利和本公司出具的检测结果拥有所有权。

**四、对客户机密信息和所有权保护的承诺**

本公司承诺保护客户的机密信息和所有权，包括客户提供的标准方法、技术要求、说明书、委托检验合同等与检测有关的所有文件，以及受检物品和检测结果，本公司应设专人管理，并为其保密。在能力验证时，也应保护参加公司及客户的机密，保密和保护所有权的程序执行《保护客户机密信息程序》。

**五、本公司对认可机构的承诺**

1. 遵守《中国合格评定国家认可委员会章程》，遵守《实验室认可规则》（CNAS\-RL01：2025）和《检验检测机构资质认定评审准则》（2023年版），接受中国合格评定国家认可委员会和市场监督管理部门的监督；
2. 严格按照《检验检测机构资质认定评审准则》（2023年版）和CNAS\-CL01:2018的要求管理实验室，执行本公司《质量手册》规定的各项制度；
3. 加强公司的管理，提高技术水平，使实验室以公正的行为、科学的方法、准确的数据为客户提供服务；
4. 积极配合中国合格评定认可委员会的工作，将本公司建成可以依赖的实验室。

**六、本公司员工守则**

1. 认真学习和贯彻国家关于检测活动的有关法律法规和规章；
2. 自觉执行和遵守实验室的检测程序和规章制度；
3. 努力推进实验室质量方针的贯彻；
4. 坚持热情为客户服务的宗旨；
5. 严守检测机密，做到诚实正派；
6. 刻苦钻研技术，提高检测质量；
7. 做好本职工作，相互团结帮助；
8. 维护客户利益，提高服务效率；
9. 避免介入客户的市场竞争和利益冲突；
10. 检测人员尽量避免与客户直接接触；
11. 不从事有损本实验室名誉和利益的活动；
12. 抵制一切背离质量方针的行政干预和压力。
13. 从事检测活动的人员不得同时在任何其他实验室兼职。

# **附录15：各岗位任职资格条件**

本附录规定了本公司各关键岗位及支持岗位的任职资格要求，由实验室主任批准发布，人员变更时应同步审查相应岗位要求。

**一、管理层岗位**

**1\. 实验室主任**

1. 热爱本职工作，具有很强的组织管理和协调能力；
2. 大专及以上文化程度，宝石学专业或具有专业珠宝鉴定师资格证（CGC、 FGA等），有三年以上实验室工作、管理经验；
3. 接受过《检验检测机构资质认定评审准则》等相关培训，并考核合格；
4. 熟悉本公司管理体系文件中与之相关的规定、要求，熟悉本公司所开展的检测工作要求。

**2\. 技术负责人**

1. 大专及以上文化程度（珠宝鉴定或相关专业毕业），具有中级及以上技术职称或同等能力，熟悉检测技术，经实验室主任任命；同等能力认定标准：博士研究生毕业从事相关专业检测活动1年及以上；硕士研究生毕业从事相关专业检测活动3年及以上；大学本科毕业从事相关专业检测活动5年及以上；大学专科毕业从事相关专业检测活动8年及以上。
2. 接受过《检验检测机构资质认定评审准则》等相关培训，并考核合格；
3. 能够处理检测工作中出现的重大技术问题，能准确判断检测结果的正确性，能够对检测结果提出意见和解释。

**3\. 质量负责人**

1. 大专及以上文化程度，经实验室主任任命；
2. 接受过《检验检测机构资质认定评审准则》等相关培训，并考核合格；
3. 掌握本公司管理体系文件中与之相关的规定、要求；熟悉本公司所开展的检测工作要求；掌握资质认定评审准则及计量认证的有关要求。

**二、技术检测岗位**

**4\. 检测室主任**

1. 大专及以上文化程度，宝石学专业或具有珠宝鉴定师资格证（CGC、 FGA、GIC、 NGTC等），从事相关专业检测活动5年及以上；
2. 接受过《检验检测机构资质认定评审准则》等相关培训，并考核合格；
3. 熟悉本公司管理体系文件，熟悉所开展的检测工作要求。

**5\. 授权签字人**

1. 大专及以上学历（珠宝鉴定或相关专业），具有中级及以上技术职称或同等能力（同等能力认定标准同技术负责人）；
2. 掌握质量管理程序、签字领域的标准和方法、报告签发程序；对检测结果有正确的判断力；
3. 熟悉资质认定准则和相关法律法规，并经资质认定部门批准；
4. 对测试结果的完整性和准确性负责，有能力对相关检测结果进行评定，了解测试结果的不确定度；
5. 熟悉评审机构对实验室的要求，熟悉认可标识和印章的使用规定。

**6\. 检测员（检测师）**

1. 珠宝或相近专业大专及以上学历，或经过专业培训并取得相应的资格证书，具有珠宝鉴定师相应资质；
2. 掌握本公司从事检测项目的技术要求、试验条件及试验方法；
3. 熟悉掌握检测方法，具备产品检测能力；有一年以上实验室工作经验；
4. 经上岗前培训考核合格，获得实验室主任颁发的上岗授权书。

**7\. 监督员**

1. 大专及以上文化程度；有两年以上实验室工作经验；
2. 熟悉各项检测方法、程序、目的和结果评价；
3. 熟悉本公司监督范围内管理体系文件的各项规定；
4. 具有法规和标准中阐明的通用要求的知识；了解物品正常使用中偏离所产生的影响程度。

**8\. 意见解释人**

1. 具有中级及以上相关专业技术职称或同等能力；
2. 3年以上珠宝玉石检测工作经历；
3. 熟悉检测业务、检测方法、检测程序、检测结果的应用，熟悉相关法律法规和标准。

**三、管理支持岗位**

**9\. 办公室主任**

1. 大专及以上文化程度；有一定的管理工作经验；
2. 具有较强的组织和书写能力；掌握本公司管理体系文件中相关规定和要求。

**10\. 资料管理员**

1. 具有高中及以上学历；熟悉掌握档案管理工作，具有相关工作经验及较强的文档管理能力；
2. 工作细心，熟悉资料档案管理规定；能够完成管理体系文件中相关规定和要求。

**11\. 设备管理员**

1. 具有仪器设备计量、仪器设备维护相关知识；具有一定设备管理工作经验；
2. 熟悉仪器设备的维护保养规定；熟悉本公司管理体系文件中相关规定和要求。

**12\. 样品管理员**

1. 具有高中及以上学历；熟悉本公司的检测能力范围；
2. 熟悉检测样品的接收登记管理规定；熟悉检测业务和标准规范，具有相关工作经验。

**13\. 财务人员**

1. 具有会计从业资格证书，具有两年以上财务工作经验；了解国家财经政策和会计、税务法规；
2. 熟悉会计报表处理，熟练使用财务工具和办公软件；具有良好的职业操守，作风严谨。

**14\. 内审员**

1. 大专及以上文化程度；有一年以上实验室工作经验；经实验室主任任命；
2. 接受过内审员培训，考核合格，执有内审员证书；
3. 熟悉本公司审核范围内相关检测项目的技术要求及管理体系文件的各项规定。
