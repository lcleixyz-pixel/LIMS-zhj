# 不好用清单

> 边用边记。这是后面所有改进（UI、字段、模板、流程）的唯一依据。
> 怎么记：发现一处就加一行，写清"在哪、什么问题、多烦"。能截图最好，截图发给 Claude 也行。
> 不用写得很正式，看懂就行。攒一批我来分类、排优先级。

## 记录方法

| 列 | 写什么 |
|---|---|
| 日期 | 哪天发现的 |
| 在哪 | 哪个页面、哪个记录模板（如"记录填写-培训记录"） |
| 类别 | UI外观 / 字段不对 / 流程啰嗦 / 模板内容 / 报错 / 其他 |
| 问题 | 一句话描述 |
| 多烦 | 挡路（没法继续）/ 有点烦（能用但别扭）/ 锦上添花 |
