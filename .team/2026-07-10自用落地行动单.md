## 开始前：你电脑上需要有 Docker

这套系统跑在 Docker 里（一个"虚拟小电脑"），所以第一步是确认 Docker 装好了。

- **怎么看有没有**：打开电脑上的"终端"（Mac 在"启动台"搜"终端"），输入 `docker --version` 回车。
- **成功标志**：显示一行类似 `Docker version 24.x.x`。
- **如果没有**：去 [docker.com](https://www.docker.com/products/docker-desktop/) 装 Docker Desktop，装完打开它（菜单栏出现鲸鱼图标算开着）。

> 我帮不了你装 Docker，这步得你自己来。装好后告诉我。

---

## 第 1 步｜启动系统（预计 5–15 分钟，首次会下载镜像）

- **做什么**：把 jewelry-qms 跑起来。
- **怎么做**：终端里粘这两行（一行一行来，等第一行跑完再跑第二行）：

```bash
cd "/Users/lc.leixyz/Documents/AI工作台/01-项目代码/LIMS-zhj/jewelry-qms"
docker compose up --build
```

- **怎么算成功**：屏幕滚很多行后，看到类似 `Started server on 0.0.0.0:8010` 或没有报错停住。打开浏览器访问 `http://localhost:8010`，能看到登录页。
- **卡住了**：把最后 20 行红字复制给我。常见问题是 8010 端口被占用——关掉占用的程序，或我们改端口。
- **注意**：这个终端窗口要一直开着（它就是服务器）。关了系统就停了。

---

## 第 2 步｜确认两张记录表已建（预计 1 分钟）

Docker 启动时通常会自动建表。我们确认一下。

- **怎么做**：**新开一个终端窗口**（原来的别关），粘这行：

```bash
docker compose exec app php think migrate:status
```

- **怎么算成功**：看到一张表，里面 `record_form_templates` 和 `record_form_instances` 都标 `up`。
- **如果显示 down 或没有这两行**：跑这行导入：

```bash
docker compose exec app bash -c "mysql -uroot jewelry_qms < database/jewelry_qms.sql"
```
然后再跑一次 migrate:status 确认。

---

## 第 3 步｜灌入 9 个样板记录模板（预计 1 分钟）

- **做什么**：把系统自带的 9 个人员类记录模板（培训记录、持证登记等）一键灌进去，这样你马上有东西可填。
- **怎么做**：登录系统后，进 **记录表格模板** 页面，点 **写入样板** 按钮（或在浏览器访问 `http://localhost:8010/record_form_template/seedSamples`）。
- **怎么算成功**：页面提示"已写入样板模板 9 条"，列表里能看到"年度培训计划""培训记录"等。

---

## 第 4 步｜试填 1 个真实记录（预计 10 分钟）

这是**今天最关键的一步**——用你机构的真实数据填一份。

- **做什么**：挑一个最常用的记录模板（比如"人员培训记录表"），点 **填写记录**，照着你们平时纸质表的内容填进去。
- **重点**：填的是**真实机构、真实人、真实培训内容**。这是验证系统好不好用的唯一办法。
- **怎么算成功**：点保存后，记录出现在"记录填写记录"列表里，状态是 draft。

---

## 第 5 步｜验证打印预览（预计 2 分钟）

- **做什么**：看填好的记录能不能变成一张 A4 样式的表。
- **怎么做**：在记录详情页点 **打印预览**。
- **怎么算成功**：弹出一张排版整齐的 A4 页面，有标题、编号、你刚填的内容。
- **看不顺眼的地方**：截图给我（边距太挤？字太小？表格断了？），这些就是明天要记的"不好用"清单。

---

## 第 6 步｜验证 PDF 导出（这步稍难，不强求今天成）

- **做什么**：把那张 A4 变成 PDF 文件。
- **前置**：PDF 靠一个叫 Playwright 的工具，要先装浏览器内核。在**新终端**跑：

```bash
cd "/Users/lc.leixyz/Documents/AI工作台/01-项目代码/LIMS-zhj/jewelry-qms"
docker compose --profile pdf run --rm pdf npx playwright install chromium
```

- **然后**：回记录详情页点 **生成 PDF**，再点 **下载 PDF**。
- **怎么算成功**：下载到一个能打开的 PDF。
- **如果装不上或失败**：**先跳过**。打印预览（第 5 步）能用，明天就算达标。PDF 可以后天再搞。

这份"不好用清单"是后面改进的唯一依据，比 100 份治理演练报告都值钱。
