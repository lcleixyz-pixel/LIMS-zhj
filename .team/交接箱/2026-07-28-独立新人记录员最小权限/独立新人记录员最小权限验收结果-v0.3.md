# 独立新人记录员最小权限验收结果 v0.3

## 结论

通过。8021 的 `sim_recorder` 已形成独立、中文友好、后端强制的数据范围：有效任命时可完成本人记录闭环；任命失效时只保留本人历史记录只读能力，不会回落为权限更宽的普通员工。

本结果只适用于 `GOV-TRIAL-20260724` 治理试运行环境。纸质体系仍是唯一正式体系；本轮未写入、迁移或部署 8010。

## 最终权限边界

1. 有效 `record_operator` 任命：可选择模板、新建、编辑本人草稿、打印/下载、生成本人 PDF、申请本人记录更正。
2. 他人记录：详情、编辑、打印、下载、更正和生成产物均由统一中间件返回 HTTP 403。
3. 任命失效、过期、撤销、取消发布或软删除：导航只保留工作台、本人记录和通知；只能查看、打印和下载本人既有记录，不能进入模板、新建、编辑、申请更正或生成 PDF/当前记录包。
4. 后续另有有效技术负责人等业务岗位任命：按新岗位正常工作，不会被历史记录员身份永久锁死。
5. 年度运行确认、模板复核、体系文件、投诉、岗位责任和其他管理模块不可进入。
6. 设备管理员等专项岗位只叠加其专项动作，不会放开体系文件、投诉或全部记录范围。

## 复核后加固

- 身份、有效岗位和记录员上下文采用请求内缓存，避免页面菜单反复查询数据库。
- 所有记录详情、打印、下载、更正、编辑和 PDF 路由显式映射动作权限，不依赖隐藏按钮。
- 8021 建号脚本固定读取 `qms.company_id`，机构不存在时停止；同名账号、员工号、岗位或任命键若指向其他机构、停用数据或其他人员，拒绝覆盖。
- 记录编辑页与新建页统一必填、条件必填、单位、占位说明、中文可访问名称和集中错误汇总。
- 重复表格的整行空白不触发必填；一旦开始填写，该行仍按字段规则校验。
- 失效岗位直接编辑时显示明确中文原因，不再误提示为“正在访问他人记录”。
- 失效岗位的列表和详情不再展示新建、编辑、生成 PDF、申请更正、当前 PDF 或归档包等死路入口，只保留查看、打印和原始 PDF 下载。
