# 岗位任命调整建议 v0.1

- 日期：2026-07-14
- 评估对象：机构现有岗位与任命结构
- 结论：**需要调整，但以明确组织层级、职责边界、授权范围和回避机制为主，不建议在未做能力核验前直接更换人员。**
- 文件状态：治理建议草案，待机构确认；不是任命决定

## 一、判断边界

现行准则并不当然禁止一人兼任多个岗位，也不要求质量负责人或技术负责人只能有一人。CNAS-CL01-G001:2024 5.2 允许由一个人或一个团队对实验室活动全面负责。因此，本次不以“兼岗数量”直接判不符合，而是检查：

- 最终责任人是否明确；
- 两场所和各技术领域是否都有清晰覆盖；
- 人员是否具备经证明的能力；
- 授权是否写明场所、项目、权限和有效期；
- 内审、监督、批准等活动是否存在自审、自批或无人替代；
- 变更后是否按 CMA 要求办理报告或批准手续。

## 二、现有任命的主要优点

1. 已覆盖质量、技术、授权签字、内部审核、监督、设备、资料、样品和检测等主要岗位。
2. 乌鲁木齐与和田两场所均设置了检测室、办公室、设备、资料、样品和检测岗位。
3. 授权签字人和监督员不是仅设置一人，具备建立替代安排和交叉监督的基础。

## 三、建议调整项

### A. 必须明确后才能进入真实岗位试运行

| 调整项 | 当前风险 | 建议口径 |
|---|---|---|
| 最高管理层 / 实验室总负责人 | 截图未显示谁对实验室活动承担最终管理责任；程序中又混用“总经理、最高管理者、实验室主任、经理”等称谓 | 若已有正式任命，补入组织结构和岗位映射；若没有，任命一名最高管理者或实验室总负责人，并统一各文件称谓 |
| 两名质量负责人 | “共同负责”未说明谁统筹、谁替代、按场所还是按过程分工 | 建议设“质量负责人 + 质量负责人代理人/场所质量协调人”；如确属团队负责，应写明各自范围、最终裁决权和替代顺序 |
| 两名技术负责人 | 未说明按技术领域、场所或上下级分工 | 可保留两人，但应按乌鲁木齐/和田或技术领域明确范围，并指定总体技术责任、互为替代条件和超范围升级路径 |
| 四名授权签字人 | 截图只证明人员名单，未证明每人的场所和授权技术范围 | 逐人建立“场所 + 检测领域/项目 + 报告类型 + 授权起止 + 能力证据”；多场所应分别列明，不得笼统全范围授权 |
| 两名内审员 | 质量、技术、授权签字、场所管理等兼岗较多，容易审核到本人负责的活动 | 建立交叉审核和回避矩阵；原则上不审核本人直接负责或批准的活动。无法回避时，采用跨场所审核或引入合格外部内审员 |
| 两名监督员 | 截图未显示是否覆盖和田场所、全部检测人员和技术活动 | 明确每名监督员覆盖的场所、方法/项目和人员；不得由人员对自己的工作实施监督并作出能力确认 |
| 人员能力与授权证据 | 任命名单不能替代能力确认 | 每个关键岗位补齐任职条件、学历/职称/经历、培训、能力评价、授权范围、批准人、有效期和定期复核记录 |

### B. 建议优化，不宜单凭兼岗直接判不符合

1. **降低质量与技术岗位对日常操作岗位的过度集中。** 现有结构中，质量/技术岗位还兼任内审、签字、监督、设备或资料等职责。人员允许时，优先将资料控制、设备日常管理等执行性工作交给场所岗位人员，质量/技术负责人保留监督与批准职责。
2. **和田样品管理与检测兼岗设置独立复核。** 如暂时不能拆分，应增加样品交接、状态标识、访问控制、检测任务分派和结果复核证据，避免同一人从接样到结果放行形成完整闭环。
3. **给每个关键岗位设置替代人。** 重点包括最高管理者、质量负责人、技术负责人、授权签字人、设备管理员、资料管理员和样品管理员，写明代理触发条件及代理权限边界。
4. **把“资料管理员”统一为文件/记录控制岗位。** 在手册、程序、组织结构、LIMS 角色中统一名称，区分文件批准权、发放维护权和记录保管权。

### C. 为 LIMS 试运行新增的系统职责

现有纸面任命尚未覆盖计算机化系统运行所需职责，建议另行授权，不一定新增编制：

| 系统职责 | 主要权限 | 必须回避 |
|---|---|---|
| LIMS 系统管理员 | 建号、停号、基础配置、故障处理 | 不得自行批准自己的权限，不得替业务岗位批准体系记录 |
| 账号与权限批准人 | 审批账号、岗位角色和权限变更 | 不得与执行建号的人形成无复核的单人闭环 |
| 数据备份与恢复执行人 | 执行备份、恢复演练、留存日志 | 恢复结果应由另一名人员复核 |
| 审计日志 / 安全复核人 | 定期查看登录、权限和关键数据变更 | 不宜由被检查的系统管理员单独完成并关闭问题 |
| 业务数据责任人 | 确认部门、人员、设备、方法等主数据 | 不直接获得超出业务职责的系统管理权限 |

## 四、推荐组织表达方式

建议采用“四层表达”，避免把所有任命挤在一张名单里：

1. **机构层：**最高管理者或实验室总负责人、质量负责人及代理、总体技术负责人及场所/领域技术负责人。
2. **场所层：**乌鲁木齐、和田的场所负责人，以及设备、文件/记录、样品管理岗位。
3. **专业授权层：**授权签字人、监督员、内审员、检测人员，逐人列场所和范围。
4. **系统运行层：**LIMS 系统管理、权限批准、备份恢复、日志复核和业务数据责任。

## 五、建议保留、调整与暂缓决定

| 类型 | 建议 |
|---|---|
| 可先保留 | 两场所负责人、设备/资料/样品岗位、现有检测人员名单；待核验职责和能力后转入正式矩阵 |
| 调整表达 | 两名质量负责人、两名技术负责人：从并列且边界不明改为主责/代理或按场所、技术领域清晰分工 |
| 专项复核 | 四名授权签字人、两名内审员、两名监督员：核能力范围、场所覆盖、独立性和回避机制 |
| 新增授权 | 最高管理层最终责任、LIMS 系统职责、各关键岗位替代人 |
| 暂不执行 | 不直接发布新任命，不在 LIMS 中创建真实任命和生效责任链，不向云端导入人员数据 |

## 六、G1 最小交付物

在调整正式任命前，先形成并由机构确认以下 6 张表：

1. 组织结构与岗位称谓映射表；
2. 关键岗位职责、权限和替代表；
3. 授权签字人分场所、分领域授权表；
4. 监督员覆盖矩阵；
5. 内审交叉审核与回避矩阵；
6. LIMS 角色与最小权限矩阵。

六张表确认后，再决定哪些任命需要重新发文、哪些只需补充附件或岗位说明书。涉及最高管理者、技术负责人、授权签字人等 CMA 登记事项的变更，应在正式执行前核对报告、批准或备案要求。

## 七、依据与强制性说明

- **强制/认可要求：**CNAS-CL01:2018 5.5、6.2.4—6.2.6、7.11、8.8；CNAS-CL01-G001:2024 5.2、5.5a、6.2.2、6.2.5；《检验检测机构资质认定评审准则》第九条等。
- **治理建议：**主责/代理模式、减少执行性兼岗、四层组织表达和 LIMS 职责拆分，是为满足职责清晰、能力、独立性和数据完整性要求提出的实施方案，不是准则规定的唯一组织形式。

## 八、下一道闸门

机构确认本建议后进入 G1：生成六张岗位治理表及逐文件修订矩阵。未确认前不变更正式任命，不写 LIMS 责任链，不进行真实账号云端试运行。
