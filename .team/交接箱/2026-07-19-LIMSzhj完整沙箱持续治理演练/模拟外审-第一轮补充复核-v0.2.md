## 3. 原 MAJ-01 补充判定

### 3.1 原发现

管理评审被标记完成，但页面存在多类 8.9.2 输入“未形成/待补充”，且 8.9.3 决议跟踪为空。

- 条款：ISO/IEC 17025:2017 / CNAS-CL01 8.9.2、8.9.3；关联 8.4、7.11.3(d)
- 原级别：主要项

### 3.2 新证据支持关闭的子问题

v0.4 日志新增并通过以下严格断言：

1. 已完成管理评审具有可校验的 18 类冻结输入快照；
2. 18 类输入可以独立下钻；
3. 资源充分性已经拆分为设备和人员；
4. 未截断分类的计数与明细 ID 一致。

更新截图还将 18 类输入及其形成状态直接写入“评审输入”摘要。由此可以确认：

- 输入快照不是页面临时拼接；
- 分类数量、明细数量和下钻关系具备机器可校验性；
- 原报告关于“输入状态的数据库/页面数据完整性无法确认”的疑虑已经消除。

该子问题关闭。

### 3.3 仍未关闭的实质问题

更新后的页面仍明确显示以下 7 类输入为“未形成/待补充”：

1. 8.9.2.a：以往管理评审所采取措施的状态；
2. 8.9.2.b：与管理体系相关的内外部问题变化；
3. 8.9.2.c：质量目标实现情况；
4. 8.9.2.g：外部机构评审结果；
5. 8.9.2.h：工作量、工作类型或活动范围变化；
6. 8.9.2.m：风险识别结果；
7. 8.9.2.o：其他相关因素——日常监督。

其中，首次管理评审没有上期措施、尚无外部评审，可以记录“首次评审/本期无此活动/不适用及理由”，但不能以“未形成/待补充”后直接完成评审。质量目标、内外部问题变化、工作量/范围变化、风险识别和日常监督均属于应在管理评审中评价的输入；当前页面没有显示评价结论或不适用理由。

同时：

- “评审决议跟踪”仍为空；
- “评审输出”只有一行概要，没有形成可追踪的决定、责任人、期限、资源和状态；
- v0.4 的 MRR01—MRR04 验证的是**快照完整性、可下钻性和计数一致性**，没有断言所有适用输入已评审，也没有断言 8.9.3 决议已经形成和跟踪。

### 3.4 判定

| 判定维度 | 结果 |
|---|---|
| 18 类快照完整性 | 关闭 |
| 分类可下钻及计数一致性 | 关闭 |
| 8.9.2 适用输入已全部评价 | 未关闭 |
| 8.9.3 决定与行动可追踪 | 未关闭 |
| 原 MAJ-01 总体状态 | **保持主要项，不降级** |

关闭要求：

1. 7 类未形成输入逐项补充；确无活动的项目须记录“不适用/本期无”及理由；
2. 对每一适用输入形成管理层评价；
3. 将输出拆成可跟踪决议，至少包含决定、责任人、期限、资源需求、状态和完成证据；
4. 增加严格断言：完成状态不得与未评价的适用输入并存；完成状态必须至少存在一条满足 8.9.3 的决议/行动记录。

## 8. 是否允许进入第二轮

结论：**不允许。**

理由不是原 MAJ-03；该项已经关闭。当前阻断第二轮的是：

1. 原 MAJ-01 仍有 7 类输入未评价，8.9.3 决议跟踪为空；
2. 原 MAJ-02 的合同评审锁定记录仍不具备合同评审语义；
3. 原 MAJ-04 的文件候选尚未成为受控现行文件；
4. 原 MAJ-05 的正式依据、范围和真人授权证据仍不足；
5. 原 MAJ-06 的真实检测业务和真实运行仍未覆盖；
6. B-07 尚未证明各类记录模板的字段语义正确。

完成上述阻断后，应另行形成第二轮输入包并正式启动第二轮，不能把本次补充复核计为第二轮。
