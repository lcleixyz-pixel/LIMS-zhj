# G4-R5 本地候选池修复记录 v0.1

## 结论

本地候选池页面错误已定位并修复。

截图中的错误为：

```text
SQLSTATE[42S02]: Base table or view not found:
1146 Table `jewelry_qms`.`qms_external_change_candidates` doesn't exist
```

根因是：G4-R3 已新增候选池控制器、模型、路由和页面，但本地 `jewelry_qms` 数据库未补齐 `qms_external_change_candidates` 与 `qms_regulatory_monitor_runs` 两张表。

## 修复动作

1. 新增迁移：
   - `jewelry-qms/database/migrations/20260715_regulatory_candidates.sql`
2. 同步更新初始化基线：
   - `jewelry-qms/database/jewelry_qms.sql`
3. 更新 smoke 测试，要求候选池表结构进入基线：
   - `jewelry-qms/tests/qms_external_change_event_smoke.php`
4. 将迁移应用到本机 `jewelry-qms-db-1`。
