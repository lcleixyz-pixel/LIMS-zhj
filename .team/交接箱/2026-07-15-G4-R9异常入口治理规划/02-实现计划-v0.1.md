# G4-R9 异常入口治理实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 systematic-debugging 完成根因核查后，按本计划逐任务实施。每个任务完成后运行指定验证，不允许跳过失败测试。

**目标：** 让试运行人员不再从组合包页和日历页进入 ThinkPHP 错误页，同时保留历史组合包和质量追溯证据。

**架构：** 在服务层识别“历史归档行对应的当前对象是否仍存在”，在页面层将失效对象降级为历史快照展示；控制器层补友好兜底，避免直接访问旧 URL 时暴露框架错误页。日历页同样对通知目标做存在性检查。

**技术栈：** ThinkPHP8、MySQL、PHP 8、现有 smoke PHP 脚本。

---

## 文件结构

- 修改：`jewelry-qms/app/service/QmsDocumentStructureService.php`
  - 为组合包 manifest 行补充 `block_exists`、`structured_document_exists`、`is_historical_snapshot`、`stale_reason` 等字段。
  - 对失效 block 不再生成 `block_edit_url` / `trace_review_url`。
- 修改：`jewelry-qms/app/controller/PlanningStructure.php`
  - `editBlock()` / `reviewLinks()` 对不存在内容块返回友好提示并重定向。
- 修改：`jewelry-qms/app/view/planning_structure/package.html`
  - 对历史快照行显示“历史快照 / 当前内容块已重建或不存在”，不显示编辑类按钮。
- 修改：`jewelry-qms/app/controller/Calendar.php`
  - 生成待办 URL 前检查目标记录是否存在。
- 修改：`jewelry-qms/app/view/calendar/index.html`
  - 对无可达处理入口的提醒显示原因。
- 新增：`jewelry-qms/tests/qms_g4r9_stale_link_guard_smoke.php`
  - 验证组合包旧 block 不再暴露坏入口，日历不存在目标不再渲染坏链接。

## 任务 1：写失败测试

**文件：**

- 创建：`jewelry-qms/tests/qms_g4r9_stale_link_guard_smoke.php`

测试要覆盖：

1. 从当前 `manifest.json` 读取最新 `block_trace_inventory`。
2. 找出 manifest 中 `block_id` 不存在于 `qms_document_blocks` 的行。
3. 调用 `QmsDocumentStructureService::latestSystemPackageBlockTraceRows()` 后，这些行必须：
   - `block_exists === false`
   - `is_historical_snapshot === true`
   - `block_edit_url === ''`
   - `trace_review_url === ''`
   - 保留 `trace_summary`
4. 日历控制器/视图源码必须包含目标存在性检查和“关联对象不存在”提示。

运行：

```bash
docker compose -f jewelry-qms/compose.yaml exec -T app php tests/qms_g4r9_stale_link_guard_smoke.php
```

预期：

- 实施前 FAIL，提示旧 manifest 行仍暴露编辑/复核入口。

## 任务 2：服务层标记组合包历史快照

**文件：**

- 修改：`jewelry-qms/app/service/QmsDocumentStructureService.php`

实现要点：

- 在 `normalizePackageBlockTraceRows()` 中收集 rows 的 `block_id` 和 `structured_document_id`。
- 一次性查询当前存在的 blocks / structured documents，避免逐行查询。
- 对每行添加：
  - `block_exists`
  - `structured_document_exists`
  - `is_historical_snapshot`
  - `stale_reason`
- 当 `block_exists === false` 时清空：
  - `block_edit_url`
  - `trace_review_url`
- 当 `structured_document_exists === false` 时也清空 `document_url`。

验证：

```bash
docker compose -f jewelry-qms/compose.yaml exec -T app php tests/qms_g4r9_stale_link_guard_smoke.php
```

预期：

- 组合包旧 block 相关断言 PASS。
