# G4-R7 试运行可信度与候选处置闭环实施记录 v0.1

## 1. 已实施内容

### 1.1 仪表盘可信度

- `DashboardMetricService` 为图表数据补充 `has_data`。
- `dashboard/index.html` 增加 `qmsChartOrEmpty`，当数据合计为 0 时显示空态文案：
  - `暂无校准记录`
  - `暂无 CAPA 数据`
  - `暂无培训覆盖数据`
  - `暂无内审发现数据`
- 右上角通知为 0 时改为灰色角标，避免红色 `0` 造成误解。

### 1.2 法规候选池入口与术语

- `Auth` 中增加 `pendingRegulatoryCandidateCount`，用于菜单角标。
- `体系策划` 下拉菜单按以下结构分组：
  - 策划与要素。
  - 文件与追溯。
  - 外部变化管理。
  - 岗位责任。
- 固定菜单名保持 `法规候选池`，只在有待确认候选时显示数字角标。
- 候选池列表把 `samr/cnas` 一类机器来源翻译为业务来源，如 `市场监管总局`、`CNAS`。
- `unverified` 显示为 `来源待核验`。
- `first_seen_at` 列表显示精简为日期。

### 1.3 候选详情处置闭环

- 新增路由：
  - `POST /planning/regulatory-candidates/review`
  - `POST /planning/regulatory-candidates/promote`
- 候选详情页新增人工处置区：
  - 确认适用。
  - 确认不适用。
  - 暂缓。
  - 转正式变更事件。
- 增加生效状态提示：
  - 已生效 X 天。
  - 距生效还有 X 天。
  - 生效日期未标明/格式待核验。
- 六类影响表保留 `初步结论`，新增 `建议动作`，避免把机器初判误写成最终决定。
- 规则 ID 默认折叠到技术依据。
- 转正式变更事件时只创建事件台账，不自动修改体系文件、人员授权、模板、培训或 LIMS 规则。

### 1.4 正式变更事件空态

- `外部变更事件` 空态增加说明：
  - 候选经人工确认后进入这里。
  - 也可由质量负责人手工登记。
  - 提供 `去候选池看看` 链接。

### 1.5 记录模板受控纪律

- 模板列表对重复 `doc_number` 显示 `编号重复` 警示和重复数量。
- 新增/编辑模板时校验编号唯一，提示走换版或作废流程。
- `delete` 仅允许草稿模板物理删除。
- 已发布/已作废模板不显示普通“删除”，改为 `作废` 和 `作废/换版` 提示。
- 新增 `POST /record_form_template/obsolete`，将已发布模板改为 `obsolete` 并保留历史。
- `print_template_key` 以技术弱化样式显示，降低对岗位人员的干扰。

### 1.6 填写记录列表可读性

- `2025 运行确认` 改为 `2025 年度记录运行确认`。
- 列表增加 `填写人`、`审核人`。
- `generated` 状态显示为 `已形成PDF`。
- 审核人暂无时显示 `待审核`。
