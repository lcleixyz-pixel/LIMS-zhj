## 关键闭环

1. 内审：计划 → 日程 → 检查记录 → 发现 → CAPA → 关闭。
2. 文件：A/0 有效 → A/1 修订草稿 → 技术审核 → 质量批准 → A/0 作废 → A/1 分发 → 本人接收 → 试运行水印打印。
3. 管理评审：输入分类快照 → 明细下钻 → 外部证据引用 → 完成。
4. 模板：15 项逐项批准 → 真实角色填报 → 保存 → 生成 → 打印 → 来源追溯。
