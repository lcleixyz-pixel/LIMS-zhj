## 与现有导入能力的关系

| 文件 | 现有系统是否可直接导入 | 说明 |
|---|---|---|
| `documents_preimport.csv` | 部分可用 | 现有 `ImportService::importDocuments()` 只支持基础文档字段；候选手册和现行程序仍需人工判断是否新建、修订或匹配现有记录 |
| `record_form_templates_preimport.csv` | 不建议直接导入 | 需要表单字段复核、打印模板确认和 schema 复核流程 |
| `structured_documents_preimport.csv` | 需要开发导入命令 | 应走结构化文件链路，不应绕过 `qms_document_assets` 和块级追溯设计 |
| `traceability_matrix_preimport.csv` | 需要开发导入命令 | 应在条款、要素、手册章节、程序文件、记录模板 ID 均确认后写入 |
| `manual_blocks_preimport.csv` | 需要开发导入命令 | 应先确认候选手册章节内容和 stable_key |
| `external_sources_preimport.csv` | 可人工录入或开发导入命令 | 正式写入前应由文件管理员复核官网来源和查新周期 |

| 记录模板字段是否能承接真实工作 | 防止表格好看但不能填 | 各过程负责人 |
