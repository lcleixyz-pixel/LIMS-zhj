# 工程包参数替换清单

用途：指导 QMS 工程包从“通用/虚构工作版”切换为 XZTC 第五版候选修订输入。

## 必须替换

| 工程包默认项 | 当前问题 | 替换方向 |
|---|---|---|
| `{{P00:XC}}` | 虚构机构代号 | 替换为 XZTC 文件编号体系或实际简称 |
| 星辰宝玉石检测有限公司【虚构】 | 非真实机构 | 替换为新疆中和鉴珠宝玉石质量检测研究所（有限公司） |
| 单一固定场所 | 与现用手册多场所不一致 | 改为乌鲁木齐实验室、和田实验室两处固定场所 |
| CMA 已取得；CNAS 首次申请中 | 已由用户确认 | 可作为第五版候选稿资质状态口径 |
| 人员 12 名、授权签字人 2 名、CGC 1 名 | 未经确认 | 由机构实际人员台账确认 |
| 未来引入 LIMS | 用户确认 jewelry-qms 目前只作为建设中系统 | 不写入手册正文；仅写入实施计划 |
| 不开展现场抽样 | 与现用手册混写抽样要求 | 改为当前状态+启用条件两层表达 |
| 无 LIMS / 模板+Excel 验证替代 | 与当前治理方向不一致 | 区分正式电子记录、纸质记录、Excel 辅助、LIMS 治理 |

## 依据类替换

| 旧/风险表达 | 第五版处理 |
|---|---|
| `CNAS-CL01-G003:2018` | 更新为 `CNAS-CL01-G003:2021《测量不确定度的要求》（2023-01-01 第一次修订）` |
| `RBT 045-2020` / `RB/T 045-2020` | 不作为现行依据；如保留，仅列历史参考并注明已废止 |
| `RB/T 214-2017` | 不作为当前 CMA 主依据；仅历史对照 |
| `检验检测机构资质认定评审准则（2023年版）` | 保留，建议写明市场监管总局 2023 年第 21 号公告 |
| `CNAS-CL01-G001:2024` | 保留，作为与 CNAS-CL01 同步应用要求 |

## 条件开关建议

| 开关 | 当前建议 | 说明 |
|---|---|---|
| C1 多场所 | 开启多场所 | 乌鲁木齐、和田两处实验室 |
| C2 LIMS | 手册正文关闭；实施计划开启 | jewelry-qms 建设中，不作为第五版正文既成事实 |
| C3 抽样 | 默认不开展现场抽样；保留条件启用 | 与现用 7.3 保持一致但表达更清晰 |
| C4 CNAS 标识 | 待资质状态确认 | 未确认前不写已获认可 |
| C5 内部校准 | 待确认 | 不可默认无或有 |
| C6 切工分级 | 待确认 | 与能力范围和方法有关 |

## 替换后必须跑的检查

1. `qms_current_manual_bridge_check.py`
2. 工程包原有 `manual_check.py`
3. 支撑程序编号闭合检查
4. 依据现行性检查
5. LIMS 导出刷新后复检
