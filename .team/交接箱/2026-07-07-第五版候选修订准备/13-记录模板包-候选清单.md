# 记录模板包（候选清单）

文件状态：候选模板清单
用途：为第五版候选质量手册提供记录承接，并为后续 LIMS 治理导入准备字段。

## 使用原则

记录用于证明活动已经按规定实施，不替代程序文件。正式启用前，每个记录模板应完成编号、版次、保存期限、保存部门、填写责任、复核要求和保密等级确认。

## 样表字段规范

每个记录模板至少应具备以下通用字段：

| 字段 | 说明 |
|---|---|
| 记录编号 | 与记录清单一致，不得重复 |
| 记录名称 | 与受控记录目录一致 |
| 适用条款 | 对应 ISO/IEC 17025 / CNAS-CL01 条款 |
| 关联程序 | 对应 2022 程序文件编号 |
| 填写责任 | 岗位，不写个人姓名 |
| 形成时机 | 何时必须形成记录 |
| 复核/批准 | 需复核或批准的岗位 |
| 保存位置 | 纸质、电子或二者并行 |
| 保存期限 | 正式发布前待确认 |
| 保密等级 | 普通、内部、客户敏感或待确认 |
| 更正规则 | 保留原始信息、原因、日期、责任人和复核 |

## 后续治理动作

1. 由质量负责人确认哪些记录已经存在、哪些需要新增或修订。
2. 由文件管理员为记录模板分配正式编号、版次和保存期限。
3. 由各过程负责人试填 1 份样表，确认字段能承接真实工作。
4. 建设中系统正式纳入前，先保留纸质或现有电子记录路径；系统确认通过后再迁移字段。
