# G2-R 敏感数据排除清单 v0.1

- 日期：2026-07-15
- 适用对象：`artifacts/migration-database-g2r-sanitized.sql.gz`
- 结论：脱敏迁移包可用于下一步本地/云端迁移前审查；不得把原始源库快照作为云端迁移包。

## 1. 已排除或替换

| 对象 | 处理 | 原因 |
|---|---|---|
| `user_sessions` | 清空 | 登录会话不应迁入云端 |
| `users.password` | 统一替换为 `G2R_REDACTED_GENERATE_ON_TARGET` | 旧密码哈希不进入迁移包；云端必须重新生成密码 |
| `users.email` | 置空 | 本轮试运行不需要邮箱 |
| `users.last_login` | 置空 | 历史登录时间不迁入云端 |
| `employees.email` | 置空 | 避免非必要联系方式进入公网云服务器 |
| `employees.phone` | 置空 | 避免非必要联系方式进入公网云服务器 |

## 2. 允许保留

| 对象 | 保留理由 |
|---|---|
| 真实人员姓名 | 真实组织受控试运行需要岗位与人员关系 |
| 场所、岗位、职责链草案 | 试运行核心对象 |
| 质量体系文件目录、结构化文件、记录模板 | 质量管理试运行核心对象 |
| 一单一库候选 JSON | 候选复核包，不写入正式对象 |

## 3. 暂不迁入或必须复核

| 对象 | 状态 |
|---|---|
| 客户身份、样品、检测原始数据、正式报告、收费数据 | 本系统当前不承接检测业务，禁止迁入 |
| 用户密码、登录会话、服务器私钥、SSH 密钥 | 禁止迁入；在目标服务器重新生成或配置 |
| 员工手机号、身份证号、私人邮箱 | 默认不迁入，除非后续有明确合法必要性 |
| 附件原件 | 本地 `file_uploads=0`，但后续若有附件必须单独列清单和 hash |

## 4. 重要提醒

`artifacts/source-jewelry_qms-before-g2r.sql.gz` 是本地源库原始备份，只作为本机预演证据和回滚参考，不应上传云端。后续若进入 G3-R，应只考虑 `migration-database-g2r-sanitized.sql.gz` 或重新生成的同等脱敏包。
