# jewelry-qms 签批与换版流程图 v0.2

> 2026-07-20 · 随 2.2.0 发版准备升版（v0.1 无 DocuSeal 闸门）

```mermaid
flowchart TD
  draft[体系文件草稿] --> preview[预览层人审]
  preview --> gate{G-3状态守卫}
  gate -->|非授权写approved/effective| blocked[blocked拒绝]
  gate -->|授权路径| signReq[DocuSealService建签]
  signReq --> ds[DocuSeal内网签署]
  ds -->|Webhook验签防重放哈希比对| asset[qms_document_assets落已签件]
  ds -->|驳回| rejectCount{驳回轮次}
  rejectCount -->|小于等于3| preview
  rejectCount -->|大于3| freeze[防振荡冻结待人工]
  asset --> effective[受控生效]
  effective --> pilot[Phase4真实换版试点]
  pilot --> digest[逐批消化人审67与阻断392]
```

## 说明

1. AI / 非 Approval 路径不得直写 `approved` / `effective`（G-3）。
2. DocuSeal 仅 compose profile `signing`，默认不随现用 8010 启动。
3. QMS `users` 为签署身份事实源；控制台管理账号独立强口令。
4. SIMULATED 标记不计完成项。
