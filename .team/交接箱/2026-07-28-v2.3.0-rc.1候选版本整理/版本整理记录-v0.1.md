# v2.3.0-rc.1 候选版本整理记录

## 一、结论

本次把 `v2.2.0` 之后已在 8021 治理试运行环境验证的开发成果，整理为本地候选版本 `2.3.0-rc.1`。

这是候选版整理，不是正式发布：

- 8021 运行配置标识为 `2.3.0-rc.1`；
- 8010 运行配置继续保持稳定版 `2.2.0`；
- 不合并 `main`；
- 不推送远端；
- 不部署或写入 8010；
- 纸质体系仍是唯一正式体系。

## 二、版本范围

候选版本汇总范围为 `v2.2.0..v2.3.0-rc.1`，主要包括：

1. 治理连续正文、冲突审查、装配清单与文件治理工作台；
2. 文件签批试运行闭环、附件下载和操作反馈修复；
3. 记录字段级追加更正、原值保留、当前状态 PDF、原始 PDF 和更正链；
4. 记录模板修订草稿、换版路径和旧版保留；
5. 通用追溯语义防错、候选链与治理队列；
6. 四角色中文交互优化、独立新人记录员权限；
7. 内部部门、岗位、人员选择和日期填写控件。

详细使用者可见变化以仓库根目录 `CHANGELOG.md` 为准。

## 三、双锚点设计

由于 8010 与 8021 共用本地源码挂载，不能直接把默认运行版本改成候选版。本次采用：

| 锚点 | 值 | 用途 |
|---|---:|---|
| `stable_version` | 2.2.0 | 当前稳定版本 |
| `candidate_version` | 2.3.0-rc.1 | 当前治理试运行候选版本 |
| `version` 默认值 | 2.2.0 | 未显式配置的运行环境保持稳定版 |
| 8021 `QMS_APP_VERSION` | 2.3.0-rc.1 | 仅治理试运行环境显示候选版 |

## 四、同步的版本锚点

| 记录模板修订与换版 | 通过 |

以下事项不在本次范围：

- 正式受控文件发布；
- 治理文件内容定稿；
- 合并 `main` 或推送远端；
- 8010 镜像重建、数据库迁移或部署；
- 将候选版作为 CMA/CNAS 正式运行证据。

## 六、后续转正条件

候选版转为稳定版前，应至少完成：

1. 8021 集中验收并关闭候选缺陷；
2. 确认文件治理内容达到试运行要求；
3. 重新执行完整版本回归；
4. 取得合并、推送和 8010 部署的单独授权；
5. 生成稳定版本号和正式发布记录。
