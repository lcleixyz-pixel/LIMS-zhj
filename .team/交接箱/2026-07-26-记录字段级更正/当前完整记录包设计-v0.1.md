# 当前完整记录包设计 v0.1

日期：2026-07-26

适用环境：8021 治理试运行沙箱

## 目标

补齐系统更正与已生成 PDF、已打印纸质记录之间的载体断点。原始 PDF 始终保持冻结；发生批准后的更正时，系统提供“当前完整记录包”，供电子归档或打印后与原纸质记录一并保存。

## 已确认方案

1. 原始 PDF 不改写、不重新生成。
2. 更正附页继续单独打印，页内保留原记录编号、字段位置、原值、新值、原因、登记及批准信息。
3. 当前完整记录包使用 ZIP，包含：
   - `00-阅读说明.txt`；
   - `01-原始记录-*.pdf`；
   - `02-更正附页-*.pdf`。
4. 阅读说明列明生成时间、更正条数、最后更正时间、原始 PDF 的 SHA-256，以及“附页须与原记录一并保存”的要求。
5. 列表页显示“有后续更正”及条数；详情页优先提供“下载当前完整记录包”，并把“下载原始 PDF”降为辅助入口。
6. 没有已批准更正时不生成记录包，仍按原流程下载原始 PDF。

## 数据与安全边界

- 记录包只读取既有原始 PDF 和已批准的追加式更正记录。
- 不更新 `record_form_instances.field_values`、`generated_pdf_path` 或 `generated_pdf_name`。
- 记录包写入运行时目录，不进入正式附件字段，不改变记录状态。
- 原始 PDF 不存在、更正为空或路径无效时，服务端拒绝生成并给出明确提示。
- 8010 不执行数据库写入、不生成试运行记录包。

## 页面口径

- 主入口：`下载当前完整记录包`
- 辅助入口：`下载原始 PDF`
- 纸质操作：`打印更正附页`
- 状态提示：`存在后续更正，请将更正附页与原记录一并保存。`

## 验收标准

1. 有更正的记录在列表和详情均能识别。
2. ZIP 内三项文件齐全，阅读说明含原始 PDF 哈希和更正条数。
3. 更正附页 PDF 可以打开和打印。
4. 下载前后原记录字段和原始 PDF 路径、文件哈希不变。
5. 相关语法、路由、服务、页面和现有记录更正回归测试全部通过。
