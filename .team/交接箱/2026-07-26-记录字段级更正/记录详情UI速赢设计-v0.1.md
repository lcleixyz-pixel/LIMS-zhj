# 记录详情 UI 速赢设计 v0.1

日期：2026-07-26

适用环境：8021 治理试运行沙箱

确认来源：用户审阅 UI 巡检建议后回复“好的”，同意先实施建议第 1—5 项。

## 目标

保留原表直接批注能力，同时让记录详情页默认适合阅读、关键动作更清楚，并消除可能改变原始 PDF 基线或选错更正类型的入口。

## 已确认改动

1. 只有草稿记录可以生成 PDF；已生成记录显示“原始 PDF 已冻结”，不再提供重新生成入口。
2. 点选已有非空字段时默认“修改内容（保留原值）”；空字段默认“补充内容”；新增整行固定“补充内容”。
3. 更正面板使用可滚动弹窗，底部取消和提交按钮始终可见。
4. 详情页默认是阅读模式，不显示蓝色可编辑边框和重复“点击批注”；用户主动进入批注模式后才显示。
5. 顶部只保留当前阶段最重要的动作；下载原始 PDF、归档包和打印类动作收进“更多”菜单；不再显示无效的禁用编辑按钮。

## 页面规则

### 草稿记录

- 主动作：生成 PDF。
- 可用动作：编辑、打印预览、返回。
- 不显示批注模式。

### 已生成且有更正的记录

- 主动作：下载当前状态 PDF。
- 次动作：申请更正。
- 状态文字：原始 PDF 已冻结。
- “更多”：下载原始 PDF、下载归档包、打印预览、打印更正附页。
- 阅读模式为默认；“进入批注模式”后显示可点击字段。

### 已生成且无更正的记录

- 主动作：下载 PDF。
- 次动作：申请更正。
- 状态文字：原始 PDF 已冻结。
- “更多”：打印预览。

## 验收标准

1. 当前 `generated` 测试记录不再显示“生成PDF”和禁用“编辑”。
2. 顶部主操作不超过两个，辅助动作位于“更多”。
3. 默认阅读模式没有蓝色批注边框和重复提示；进入批注模式后全部恢复。
4. 已有备注字段打开时默认类型为“修改内容（保留原值）”。
5. 新增整行打开时类型固定为“补充内容”。
6. 1280×720 视口中弹窗底部按钮完整可见。
7. 不提交新申请，不改变原字段值、原始 PDF 和当前状态 PDF。
