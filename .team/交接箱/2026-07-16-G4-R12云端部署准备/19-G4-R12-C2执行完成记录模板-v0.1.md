# G4-R12-C2 执行完成记录模板 v0.1

日期：2026-07-16

## 用途

本模板用于用户批准 C2 后，边执行边填入实际证据。

在未获 C2 授权前，本文件只作为记录模板；不得据此 SSH、上传或修改服务器。

## 用户授权

待填写：

```text
批准 G4-R12-C2：……
```

## 执行边界确认

本轮 C2 只允许：

- 服务器只读体检；
- 升级前快照；
- 上传候选包；
- 服务器侧 SHA 校验；
- docker load；
- 解压到新 release；
- compose config 语法检查。

本轮 C2 禁止：

- 切换 `current`；
- 启动或重启容器；
- 修改 `$BASE/shared/.env`；
- 导入或迁移云端数据库；
- 开放员工登录；
- 合并 PR；
- 关闭或合并 PR #31。
