## 背景

本 PR 是云端体验试运行前的集成收口 PR。

它把两条已经分叉的工作线合并到一个可部署候选版本：

- PR #31：法规动态监测与复核技能包；
- G4-R11/G4-R12：页面试运行硬伤治理、体验部署脚本修正、本地候选包准备。

核查结果显示，PR #31 与 G4-R12 不是简单先后关系；如果直接部署旧 G4-R12 包，会漏掉法规监测实现；如果直接部署 PR #31，会漏掉近期体验部署治理修正。

## 本 PR 做了什么

- 集成 PR #31 的法规动态监测、候选池、影响初判、导出、提升复核、运行记录等能力；
- 保留 G4-R12 的页面权限过滤、记录模板入口修复、体验部署迁移脚本修正；
- 解决 5 处合并冲突；
- 增加 `composer.lock`，避免云端依赖版本漂移；
- 调整法规候选测试，避免依赖 MySQL `PROCESS` 权限，贴合体验环境最小权限边界；
- 生成新的本地候选发布包 `20260716-g4r12-pr31`。

## 与 PR #31 的关系

PR #31 当前仍是 Draft。

本 PR 不直接关闭 PR #31；它用于承接云端体验部署路径。后续可在审查确认后决定：

1. 以本 PR 作为实际合并对象，并关闭或标记 PR #31 被集成取代；
2. 或将本 PR 的冲突治理和部署修正反向整理回 PR #31。

在作出决定前，不建议同时合并两个 PR。
