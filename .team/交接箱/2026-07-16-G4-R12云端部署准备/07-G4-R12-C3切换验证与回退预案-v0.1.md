# G4-R12-C3 切换验证与回退预案 v0.1

日期：2026-07-16

## 使用边界

仅在 C2 通过后，且用户另行批准 C3 时执行。

批准口令建议：

```text
批准 G4-R12-C3：切换 current、启动集成版并运行云端验证
```

## C3 前置条件

- C1 已形成远端 Draft PR，或用户明确同意先部署后补 PR；
- C2 已完成服务器只读体检、升级前快照、包上传、SHA 校验、`docker load`、镜像架构检查；
- 新 release 目录存在：

```text
/www/server/jewelry-qms-experience/releases/20260716-g4r12-pr31
```

## C3-1 切换前记录

```bash
set -euo pipefail
BASE=/www/server/jewelry-qms-experience
PREVIOUS_RELEASE="$(readlink -f "$BASE/current")"
echo "$PREVIOUS_RELEASE" > "$BASE/shared/previous-release-before-20260716-g4r12-pr31.txt"
cat "$BASE/shared/previous-release-before-20260716-g4r12-pr31.txt"
```

## C3-2 修改 shared env 的镜像标签

```bash
set -euo pipefail
BASE=/www/server/jewelry-qms-experience
cp "$BASE/shared/.env" "$BASE/shared/.env.before-20260716-g4r12-pr31"
chmod 600 "$BASE/shared/.env.before-20260716-g4r12-pr31"
sed -i 's/^QMS_IMAGE_TAG=.*/QMS_IMAGE_TAG=amd64-g4r12-pr31/' "$BASE/shared/.env"
grep '^QMS_IMAGE_TAG=' "$BASE/shared/.env"
```

说明：法规月度自动监测默认仍保持关闭：

```text
REGULATORY_MONITOR_ENABLED=0
```

如需打开月度任务，应另行批准，不与本次切换混在一起。

## C3-3 原子切换 current 并启动

```bash
set -euo pipefail
BASE=/www/server/jewelry-qms-experience
RELEASE_ID=20260716-g4r12-pr31

ln -sfn "$BASE/releases/$RELEASE_ID" "$BASE/current"
cd "$BASE/current/jewelry-qms"
docker compose --env-file "$BASE/shared/.env" -f deploy/experience/compose.yaml up -d --pull never
bash deploy/experience/verify.sh "$BASE/shared/.env"
```

## C3-4 页面级云端冒烟

建议人工页面检查：

1. 登录页可访问；
2. 首页无 500 错误；
3. 本月待办措辞仍保持业务人员可读；
4. 记录模板入口不再跳转到空 `template_id`；
5. 法规候选池入口可在导航中找到；
6. 候选项标题和证据不再乱码；
7. 影响范围展示为候选判断，不自动改体系文件、人员授权、模板或培训；
8. 一单一库端到端案例能看到能力项目/CMA 标志、体系文件、人员授权、设备校准、LIMS 规则、培训等候选影响；
9. 组合包页面仍需观察业务人员是否看得懂，如仍难理解，应登记为试运行优化项，不阻断云端体验；
10. 页脚版本显示与部署候选一致或可由交接记录追溯。

## C3-5 回退预案

如果 `verify.sh` 或页面级冒烟失败，按以下方式回退。

```bash
set -euo pipefail
BASE=/www/server/jewelry-qms-experience
PREVIOUS_RELEASE="$(cat "$BASE/shared/previous-release-before-20260716-g4r12-pr31.txt")"

test -d "$PREVIOUS_RELEASE"
ln -sfn "$PREVIOUS_RELEASE" "$BASE/current"

if [ -f "$BASE/shared/.env.before-20260716-g4r12-pr31" ]; then
  cp "$BASE/shared/.env.before-20260716-g4r12-pr31" "$BASE/shared/.env"
  chmod 600 "$BASE/shared/.env"
fi

cd "$BASE/current/jewelry-qms"
docker compose --env-file "$BASE/shared/.env" -f deploy/experience/compose.yaml up -d --pull never
bash deploy/experience/verify.sh "$BASE/shared/.env"
```

回退后必须记录：

- 失败发生在命令验证还是页面验证；
- 失败 URL 或命令输出；
- 已回退到哪个 release；
- 是否需要保留失败版本容器日志。

## C3 禁止动作

未经单独批准，不得执行：

- `docker compose down -v`；
- 删除旧 release；
- 删除升级前快照；
- 开启 `REGULATORY_MONITOR_ENABLED=1`；
- 开放员工大范围登录；
- 导入正式业务数据或客户敏感信息。
