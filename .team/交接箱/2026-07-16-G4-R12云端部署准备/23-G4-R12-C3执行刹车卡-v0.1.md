## 用途

本卡用于用户另行批准 C3 后执行真正切换：

```text
批准 G4-R12-C3：切换 current、启动/升级、运行云端验证；如失败按回退预案恢复。
```

本卡不是批准本身。未获上述授权前，不得切换 `current`、不得修改 `$BASE/shared/.env`、不得执行 `docker compose up -d`、不得回退或重启容器。

## C3 允许动作

- 记录切换前 `current`；
- 备份 `$BASE/shared/.env`；
- 将 `QMS_IMAGE_TAG` 改为 `amd64-g4r12-pr31`；
- 原子切换 `$BASE/current` 到 `20260716-g4r12-pr31`；
- 执行 `docker compose up -d --pull never`；
- 运行 `deploy/experience/verify.sh`；
- 做页面级云端冒烟；
- 如命令验证或页面冒烟失败，按回退预案恢复到 C3 前 release。

## C3 禁止动作

- `docker compose down -v`；
- 删除旧 release；
- 删除升级前快照；
- 删除上传包；
- 开启 `REGULATORY_MONITOR_ENABLED=1`；
- 导入正式业务数据或客户敏感信息；
- 开放员工大范围登录；
- 合并 PR 或把 Draft PR 改 Ready；
- 清理前两次不完整快照。

## 页面级云端冒烟

C3 命令验证通过后，至少检查：

- 登录页可访问；
- 首页无 500 错误；
- 页面顶部仍显示“体验测试环境 / 禁止录入正式业务数据、客户资料或其他敏感信息”；
- “本月待办”措辞仍适合业务人员；
- 首页新建记录不再跳转空 `template_id`；
- 法规候选池入口可找到；
- 候选项标题、证据、影响范围不再乱码；
- “一单一库”候选影响能覆盖能力项目/CMA 标志、体系文件、人员授权、设备校准、LIMS 规则、培训；
- 候选池只给人工确认，不自动修改体系文件、人员授权、模板或培训；
- 组合包页若仍难理解，登记为试运行优化项，不作为 C3 技术回退条件。

## 停点

任一情况发生，停止并记录，不继续扩大动作：

- 本地 PR 分支不干净或未同步远端；
- PR #32 不是 Open Draft 或 mergeState 不是 CLEAN；
- 完整快照 SHA 不通过；
- 候选 release 缺文件；
- 候选镜像不是 `amd64/linux`；
- `$BASE/shared/.env.before-20260716-g4r12-pr31` 已存在；
- `verify.sh` 不通过；
- `current` 切换后不是候选 release；
- 页面出现 500、登录不可达或体验环境警示消失。
