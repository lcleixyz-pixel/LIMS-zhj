## 2. 前次 P1 关闭判定

| 检查项 | 结论 | 只读证据 |
|---|---|---|
| 任意 DML、`INSERT ... SELECT` 与敏感载荷 | 已关闭 | 验证器仅允许 `INSERT`/受限 `SET`；原始 SQL 层强制显式 `VALUES`，禁止 `ON DUPLICATE KEY UPDATE` 和 `SELECT`；按表限制允许列、必需 SIM 身份列和敏感字段值 |
| 字符串内注释绕过 | 已关闭 | 原始语句拆分与注释剥离均保留引号状态；`'/*x*/SIM-*'` 不会被当作注释清除，两个反向夹具已纳入静态门禁 |
| `INSERT IGNORE` 缺必需列 | 已关闭 | `assertFixtureRowPolicy()` 对各表逐项要求关键身份列；缺少供应商编号/名称的反向夹具被列入拒绝集合 |
| 模板精确哈希幂等 | 已关闭（单写者边界） | 模板只能 `INSERT IGNORE`；预检先在临时同构表生成候选全行，再按规范化全行 SHA256 与既有同 ID 行比较；一致可重跑，不一致拒绝且不更新 |
| 文件事务并发窗口 | 已关闭（单写者边界） | 不再用目录差异推断所有权；各实际写路径在写入前调用 `trackGeneratedPath()`，回滚仅补偿明确归属的文件，捕获窗口中新出现的无关证据不再被纳入回滚 |
