# 纯优化建议清单 v0.1

> 本清单不作为不符合，不进入自动整改关闭率，不影响第二轮通过判定；只有后续取得客观依据或用户明确采用，才可转为治理发现。

| 编号 | 建议 | 当前处置 | 不自动整改原因 |
|---|---|---|---|
| OPT-01 | 模板审查页展示 schema 哈希组、原表字段数、孤儿键和同号变体数 | 仅登记 | 属于易用性和可视化增强，不是现阶段的体系客观缺口 |
| OPT-02 | 为模板字段提供来源等级筛选 | 仅登记 | 可提升审阅效率，但不是独立的合规要求 |
| OPT-03 | 将外部依据、手册、程序、记录和 LIMS 回链图形化 | 仅登记 | Markdown 矩阵已能承载必需证据 |
| OPT-04 | 为候选变更提供人工差异预览页面 | 仅登记 | 本轮可用 Markdown + JSON + 哈希完成控制 |
| OPT-05 | 对设备变体生成结构相似度报告 | 仅登记 | 可以帮助排查，但不能替代逐变体原表和方法依据核定 |
