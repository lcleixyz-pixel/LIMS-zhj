### 3.2 数据库型法规测试：11 项双门禁

每个脚本必须同时满足 PHP 退出码 0 和最后一行明确匹配 `passed` 或 `PASS`；缺任一条件立即失败。

```sh
docker compose -p lzhj-regulatory-test \
  -f jewelry-qms/compose.yaml \
  -f jewelry-qms/compose.regulatory-monitor-test.yaml \
  exec -T app sh -lc '
    set -eu
    count=0
    for test in tests/regulatory_*_smoke.php; do
      if [ "$test" = tests/regulatory_source_registry_smoke.php ]; then
        continue
      fi
      output_file=$(mktemp)
      if ! php "$test" >"$output_file" 2>&1; then
        cat "$output_file"
        rm -f "$output_file"
        exit 1
      fi
      cat "$output_file"
      if ! tail -n 1 "$output_file" | grep -Eq "(passed|PASS)$"; then
        echo "MISSING_PASS_MARKER=$test" >&2
        rm -f "$output_file"
        exit 1
      fi
      rm -f "$output_file"
      count=$((count+1))
    done
    echo "REGULATORY_DB_SMOKES_PASSED=$count"
  '
```

实际结果：退出码 0，11 项均通过退出码和明确成功标记双门禁：
