# G4 页面错误处置记录 v0.1

记录日期：2026-07-15
服务器：`101.200.41.200`
测试域名：`qms.zhj-jc.com`
当前 release：`regmon-20260715-64fdb2a`

## 1. 现象

用户反馈“显示页面错误”。

服务器应用日志显示，登录后访问多个页面出现 500：

```text
GET /calendar/index                  500
GET /compliance/index                500
GET /department/index                500
GET /record_form_template/index      500
GET /document/add                    500
GET /                                500
```

ThinkPHP 日志根因：

```text
SQLSTATE[42S02]: Base table or view not found: 1146 Table 'jewelry_qms.system_settings' doesn't exist
```

## 2. 根因

G4 升级时只补了本次新增的法规监测和责任链目标迁移，但旧体验库还缺少此前 AI 设置模块依赖的表：

```text
system_settings
ai_chat_sessions
ai_chat_messages
```

页面布局/服务在渲染时读取 `system_settings`，因此登录后多个页面触发 500。

## 3. 处置动作

确认迁移文件 `database/migrations/20260601_ai_chat_assistant.sql` 为安全迁移：

- 仅 `CREATE TABLE IF NOT EXISTS`；
- 不包含 `DROP TABLE`；
- 不覆盖已有业务数据。

在服务器当前 release 下执行该迁移。

执行前：

```text
AI/系统配置相关表：0/3
```

执行后：

```text
AI/系统配置相关表：3/3
```
