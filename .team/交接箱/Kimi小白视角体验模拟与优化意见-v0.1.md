# 小白视角体验模拟与优化意见

> 角色：王姐，45 岁，珠宝检测实验室质量员。会用微信、能网购，没用过管理系统，看到英文会紧张。领导只交代一句：“以后文件签批、填记录都在这个系统里做。”

---

## 1. 每条旅程模拟实录

### 旅程 1：第一次登录和改密码

打开网页，标题是「珠宝检测实验室 QMS」，下面小字「CMA/CNAS 质量管理系统」。我看懂了“珠宝检测实验室”，但 QMS 是什么？心里先虚了一下。好在有“质量管理系统”五个字，我猜测这就是新系统。输入账号密码进去后，页面右上角有「修改密码」「退出」，还有个铃铛，上面写着灰色的 0。我心想 0 是什么意思？是没有消息，还是系统坏了？为什么非要把 0 摆出来？

刚登录就弹窗让我改密码，要求强口令：大小写、数字、特殊符号。我设了一个常用的，提示“强度不足”。试了三次终于通过，但我已经怕下次记不住。最疑惑的是：这个改密码是让我自己改，还是系统逼我改？弹窗没说清楚。我点了确定，总算进去了，但心里已经有点烦。

**卡点**：QMS 缩写、灰色 0 角标含义不明、强口令无示例、首次改密码缺少解释。

---

### 旅程 2：找到并看懂一份体系文件

领导说文件签批在系统里做，我先找文件。顶部导航有一排：工作台、本月待办、记录填报、体系文件、审核准备……「体系文件」带了下三角，我点开后选“文件清单”【假设】，进入列表。找到一份文件，点进去，上面一排按钮：「编辑 / 提交审核 / 发起修订 / 定期评审 / 下载附件 / ONLYOFFICE / 受控打印 / 返回列表」。

ONLYOFFICE 是什么？我以为是病毒或者插件，不敢点。状态徽章显示“已发布”“已作废”这些中文还好，但版本号“A/0”我不懂是什么意思，A 是第几版？0 又是什么？还有层级“二级 - 程序文件”，我猜“二级”是重要程度？归口部门我懂，但“复审日期”和“生效日期”并排，不知道哪个是我该操心的。

最让我愣住的是「资源管理」下拉里有一项「期间核查计划（机制入口）」。什么叫“机制入口”？是一个新的入口，还是老的计划改名了？我点了没反应，以为是坏的。

**卡点**：ONLYOFFICE 英文按钮、版本号 A/0 无说明、机制入口术语费解。

---

### 旅程 3：给文件换版签字（最核心流程）

这是领导交代的重点任务。我找到一份已发布文件，点「发起修订】。弹窗让我填修订内容，我写了“更新检测方法”，点保存，状态变成“草稿”。然后点「提交审核】。页面突然出现一块黄色卡片，标题写着「DocuSeal 签批（embed，免 SMTP）」，说明文字是“提审后生成的内嵌签署链接。按角色打开签署；不依赖邮件。”

DocuSeal 是啥？embed 是啥？SMTP 又是啥？这些词一个都不认识，只看到“签批”两个字还熟一点。卡片里有个表格，列名是“角色 / 邮箱 / 签署入口”，角色那里显示英文「Reviewer」「Approver」。我猜测 Reviewer 是审核人、Approver 是批准人，但不确定。我点了自己对应的「打开签署页】，页面中间嵌了一块签名区，上面小字写着「Reviewer · qm@lab.com】。我硬着头皮签完，状态就变成“已批准”，过了一会儿变成“已发布”。

然后页面下方有「分发记录】，要选接收人、填分发说明。输入框里灰色提示“受控副本、电子版、培训用等”。我不知道该写什么，就空着直接点「分发】。被分发的人说登录后看到「确认接收】按钮，点了就行。最后还有一个红色按钮「作废并回收】，我不敢点，红色一般都不是好事，怕点了文件就没了。

**卡点**：DocuSeal/embed/SMTP 天书、Reviewer/Approver 英文角色、签名区无明确指引、分发说明无默认值、作废按钮颜色吓人。

---

### 旅程 4：填一条记录表格

我点顶部「记录填报】，下拉出来：记录模板 / 填写记录 / 2025 运行确认 / 模板复核。我要填今天的温湿度记录，但不知道选“填写记录”还是“2025 运行确认”。点了「填写记录】，找到一条记录，详情页按钮是「打印预览 / 生成PDF / 下载PDF / 编辑 / 返回】。我点「编辑】，按钮是灰色的，悬停出来一行小字：“已形成 PDF 后不可直接编辑；如需更正，请先走作废/换版/更正流程。”

什么叫“走流程”？去哪里走？我以为点了编辑就能改，结果不让改，还让我走流程。状态那一格直接显示英文，比如 draft、archived，没有翻译。我认识的“草稿”变成了 draft，归档变成了 archived，每次都要猜。还有「PDF】格显示「未生成】，但下面又有一行「临时预览PDF】。临时预览和正式 PDF 有什么区别？我点了临时预览，出来的东西好像也能用，但我不敢确定能不能交给领导。

**卡点**：英文状态枚举、编辑入口灰掉无引导、“走流程”说法空泛、临时预览PDF用途不明。

---

### 旅程 5：处理一条不符合工作

「质量改进】下拉有三个：CAPA / 不符合工作 / 客户投诉。CAPA 是什么？四个字母我不认识，先跳过。我点「不符合工作】，看到一条待处理记录，详情页有个按钮「创建CAPA】。我以为是“创建什么计划”，点了一下，弹窗只显示「创建CAPA？】，没有解释。我点了取消，怕创建错了。

下面有「变更历史】表格，操作人一列有时显示「未知用户（岗位未登记）】。我一看“未知用户”就紧张，这是谁操作的？是不是系统出错了？后来发现这串字经常出现，好像是人员没录入岗位时的默认显示。但“未知用户”听起来像黑客或者系统问题，我建议改成“人员信息待补充”之类温和的词。

**卡点**：CAPA 英文缩写、创建 CAPA 弹窗无说明、“未知用户”措辞吓人。

---

### 旅程 6：看今天该干什么

我每天早上想先看今天有什么事。点「本月待办】，出来一个日历页，上面列了本月到期的校准、期间核查、内审节点、标准查新提醒。这个页面其实挺有用，但我找不到“今天”在哪里高亮。日历上密密麻麻都是字，我不知道哪件事是今天的、哪件是本周的、哪件已经过期的。

右上角铃铛角标，有未读时显示红色数字，无未读时显示灰色的 0。有数字的时候我知道有消息，但灰色 0 看起来像是系统还在提醒我“现在有 0 条消息”，多此一举。而且数字和 0 都挤在铃铛上，我老花眼要凑近看。

**卡点**：日历无“今天”高亮、任务无紧急度排序、灰色 0 角标多余。

---

### 旅程 7：责任链签批（质量负责人视角）

领导让我当质量负责人，我点「体系策划】→「责任链】。页面上四步导航：「1.定义职责 / 2.配置人员 / 3.校验并签批 / 4.查看已生效责任链】，旁边还有个「文件对齐（辅助）】。我看不懂“文件对齐”是什么意思，是让我对齐 Word 文档吗？辅助又辅助什么？

提示条写着“保存后仍是草案，不构成任命。完成资格校验和业务签批后，人员授权才正式生效。”这句话我读了两遍才懂，意思是保存不算数，还得签批。技术信息都折叠在「查看技术信息】小三角里，我不敢点，怕点开了看不懂。

签批区有三个按钮：「检查责任结构 / 检查签批就绪度 / 提交签批】，下面有意见框，再下面是「批准】【驳回】。我点「检查签批就绪度】，系统提示“某某岗位未配置”【假设】。我返回去改，但三个检查按钮顺序我不确定，是先点哪个再点哪个？最后我填了意见点「批准】，页面跳转到第 4 步，显示“已生效”，我才松口气。

**卡点**：文件对齐术语、检查按钮顺序不明确、技术信息折叠让人不敢点、签批提示法律化拗口。

## 3. Top 10 速赢清单（改动小、提升大）

按性价比排序，优先处理：

1. **登录页去掉 QMS 英文主标题** → 直接显示“珠宝检测实验室质量管理系统”，一眼知道这是干什么的。
2. **通知角标无消息时隐藏** → 灰色 0 天天挂在那里，既没用又让人分心。
3. **签批卡片改叫“在线签批”** → 删除 DocuSeal / embed / SMTP 所有技术词。
4. **Reviewer / Approver 改为“审核人 / 批准人”** → 角色一一对应，不会签错位置。
5. **ONLYOFFICE 按钮改为“在线编辑”** → 让用户敢点。
6. **记录状态枚举中文化** → draft→草稿、archived→已归档，每天看几十次，收益最大。
7. **首次改密码增加示例说明** → 减少反复试错，降低首次登录挫败感。
8. **编辑灰掉时给出具体入口** → “请点‘发起更正’或联系管理员”，不要让用户自己找路。
9. **本月待办增加“今日”视图** → 默认显示今天到期的任务，日历作为切换。
10. **责任链签批按钮步骤化** → 未通过检查则“提交签批”置灰，减少误操作。

## 4. 给开发团队的总体建议

王姐这类用户不是不会用电脑，而是对“管理系统”和“英文技术词”有天然的戒备。系统里每一个英文缩写、每一个技术工具名、每一个长得像代码的状态，都会让她停下来猜测、害怕点错。设计时应坚持“中文优先、业务语言优先”：界面主文案全部用中文业务词，英文缩写只在必要时以括号形式出现；状态、角色、操作结果必须翻译成日常语言，而不是直接把枚举值丢给用户。

其次，要减少“让我猜”的界面。灰色 0、机制入口、走流程、文件对齐这类说法，对开发人员是清晰的抽象，对王姐是迷雾。每一个按钮、每一个提示、每一个空状态，都要回答三个问题：我现在在哪里？我能做什么？点了之后会怎么样？把这三件事说明白，王姐才敢继续往下点。

最后，颜色和心理感受要匹配。红色按钮会让王姐犹豫甚至不敢操作；灰色的禁用状态如果没有下一步引导，会让她以为是系统坏了。建议用更温和的颜色区分“危险操作”和“次要操作”，禁用状态要同步给出“为什么点不了”和“怎么让它能点”的提示。系统不是给开发者炫技的，是让王姐每天能安心完成工作的。
