# QMS 通用语义追溯候选实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法跟踪进度。

**目标：** 让 8021 中全部 `GOV-TRIAL/0.2` 程序都能只读显示有来源的追溯候选和明确语义状态，同时保证候选不计闭环、不自动写库。

**架构：** 新增候选提供器读取现有治理装配蓝图并用本地 QMS 数据补全外部依据和记录模板；文件治理工作台把候选上下文显式注入语义门禁。实际证据链和候选链严格分开，现有逐块追溯复核仍是唯一保存入口。

**技术栈：** PHP 8、ThinkPHP 8、Think ORM、现有 PHP smoke 测试、8021 Docker 试运行容器。

```php
public static function forDocument(array $document): array
{
    $candidate = self::fromBlueprint($document, self::blueprint());
    return $candidate['available'] ? self::enrichFromDatabase($candidate) : $candidate;
}

public static function fromBlueprint(array $document, array $blueprint): array
{
    // 归一程序编号，匹配 procedure，映射 manual section key，
    // 对章节和记录编号去重、排序，并返回治理蓝图来源标签。
}
```

`enrichFromDatabase()` 只读取：

- `documents` / `qms_manual_sections`；
- `qms_element_clause_links` / `qms_clauses` / `qms_sources`；
