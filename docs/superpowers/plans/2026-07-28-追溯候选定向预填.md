# 追溯候选定向预填实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将文件治理工作台中的三类追溯候选逐条路由到合适内容块，并在现有复核表单中安全预填用途、对象和推荐理由。

**架构：** 新增一个无写库的候选路由服务，统一定义候选类型、内容块优先级和预填解析。工作台消费路由结果生成逐条入口；复核详情重新计算当前文件候选并验证候选 ID 与目标内容块，验证通过后才向页面提供预填。保存仍走现有 P0-3 门禁。

**技术栈：** PHP 8.2、ThinkPHP 8、ThinkPHP 模板、Bootstrap 5、现有 PHP smoke 测试、Docker 8021 MySQL 沙箱。

公开接口：

```php
public static function route(array $candidateTrace, array $blocks): array;
```
