# 全量 UX 审计整改实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 修复经核实成立的 8021 UX 阻断和理解问题，同时保持岗位权限、审计留痕与 8010 边界不变。

**架构：** 以“迁移防御、动作权限、角色化视图、轻量文案”四个小切面实施。先用一个静态契约 smoke 固定所有预期，再按切面逐步转绿，最后在 8021 应用单一幂等迁移并进行三角色浏览器验收。

**技术栈：** ThinkPHP 8、PHP 8.2、MySQL 8.4、ThinkPHP 模板、Bootstrap 5、Playwright。

---

## 文件职责

- `jewelry-qms/tests/qms_ux_audit_remediation_smoke.php`：本轮整改的静态回归契约。
- `jewelry-qms/database/migrations/20260727_equipment_period_checks.sql`：期间核查计划表的幂等迁移。
- `jewelry-qms/compose.governance-trial.yaml`：新建 8021 数据卷时自动装载迁移。
- `jewelry-qms/app/controller/EquipmentPeriodCheck.php`：缺表降级、设备标签和计划列表。
- `jewelry-qms/app/view/equipment_period_check/*.html`：业务标签和初始化提示。
- `jewelry-qms/app/service/ActionAuthorizationService.php`：申请中心只读访问和处理权限分离。
- `jewelry-qms/app/service/GovernedChangeService.php`、`app/controller/GovernedChange.php`、`app/view/governed_change/inbox.html`：角色化申请中心。
- `jewelry-qms/app/controller/Dashboard.php`、`app/view/dashboard/index.html`：权限一致的指标入口和图表空态。
- `jewelry-qms/app/controller/Compliance.php`、`app/view/compliance/index.html`：无权处理时显示责任提示，不输出死链。
- `jewelry-qms/app/middleware/Rbac.php`、`app/view/layout/main.html`、`route/app.php`：本人改密和导航入口对齐。
- 业务列表模板与 `config/qms.php`：中文化、状态解释、空态、支持联系人和危险操作提示。

  `company_id` varchar(36) NOT NULL,

  `plan_date` date NOT NULL,
