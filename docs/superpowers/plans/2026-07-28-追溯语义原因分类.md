# 追溯语义原因分类实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:executing-plans 在当前会话逐任务实现。步骤使用复选框跟踪进度。

**目标：** 将“章节不匹配、关系混装、尚未确认”区分为可测试的语义原因，并在工作台给出不矛盾的中文说明和下一步动作。

**架构：** 在 `QmsTraceSemanticGuardService` 内形成单条手册关系解释契约，复用 `QmsTraceRelationPolicyService` 判断历史混装；顶层状态保持兼容。工作台只消费服务输出，不自行拼接另一套原因。

**技术栈：** PHP 8.2、ThinkPHP 8、ThinkPHP 模板、现有 smoke 测试框架。
