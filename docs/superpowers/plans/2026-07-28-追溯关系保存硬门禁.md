# 追溯关系保存硬门禁实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:executing-plans 在当前会话逐任务实现。步骤使用复选框跟踪进度。

**目标：** 阻止人工复核入口新增或更新混装追溯关系，同时以中文渐进式表单和只读拆分预览指导治理人员修复历史关系。

**架构：** 使用独立无状态策略服务集中定义关系用途契约；保存服务在写库前强制校验；详情服务为历史关系附加拆分预览；视图依据同一契约渐进显示字段。自动装配和既有历史数据保持不变。

**技术栈：** PHP 8.2、ThinkPHP 8、ThinkPHP 模板、原生 JavaScript、现有 smoke 测试框架。
