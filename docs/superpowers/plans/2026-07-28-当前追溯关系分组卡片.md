# 当前追溯关系分组卡片实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将追溯复核页的当前关系宽表改为按主链证据、职责、运行入口和辅助关系组织的中文卡片，同时保留历史混装警示及全部人工操作能力。

**架构：** 新增纯展示服务，负责稳定分组、中文用途和状态、非空对象提取；`QmsDocumentStructureService` 只负责把既有关系交给展示服务；ThinkPHP 模板与少量项目 CSS 渲染响应式卡片，不新增写接口。

**技术栈：** ThinkPHP 8、PHP 8.2、ThinkPHP 模板、Bootstrap 5、现有 `qms.css`、PHP smoke 测试。

---

## 文件结构

- 创建 `jewelry-qms/app/service/QmsTraceLinkPresentationService.php`：纯函数生成优先处理区、四类业务分组、中文标签和对象清单。
- 修改 `jewelry-qms/app/service/QmsDocumentStructureService.php`：在复核详情中返回 `link_presentation`。
- 修改 `jewelry-qms/app/view/planning_structure/link_review.html`：用卡片替换当前关系宽表，保留原表单。
- 修改 `jewelry-qms/public/static/css/qms.css`：添加低动效、响应式关系卡片样式。
- 创建 `jewelry-qms/tests/qms_trace_link_presentation_smoke.php`：验证纯分组规则和兼容边界。
- 创建 `jewelry-qms/tests/qms_trace_link_cards_ui_smoke.php`：验证卡片结构与操作表单契约。
- 创建 `jewelry-qms/tests/qms_trace_link_cards_runtime_smoke.php`：验证 8021 真实关系完整进入展示模型且读取无写入。
