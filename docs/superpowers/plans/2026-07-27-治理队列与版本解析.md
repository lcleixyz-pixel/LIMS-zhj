# 治理队列与版本解析实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 `executing-plans` 逐任务实现本计划。步骤使用复选框跟踪进度。

**目标：** 为 37 份 `GOV-TRIAL/0.2` 程序建立只读治理队列，统一电子候选与来源版本角色，并支持进入下一份未完成文件。

**架构：** 新增版本解析服务负责唯一候选和版本角色；新增队列服务复用现有单文件工作台 ViewModel 形成筛选、统计和下一项计算。Controller 只处理参数、跳转和 View 赋值，Bootstrap 模板只渲染。

**技术栈：** PHP 8、ThinkPHP 8、MySQL 8、Bootstrap 5、Docker 8021 隔离数据库、现有 smoke 测试。
