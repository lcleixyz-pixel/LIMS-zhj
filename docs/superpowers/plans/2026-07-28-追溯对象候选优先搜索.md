# 追溯对象候选优先搜索实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在追溯复核页提供零依赖的中文对象搜索、本文件候选优先排序和记录要求块默认用途，同时保留原生表单与保存硬门禁。

**架构：** 新建纯数据服务，根据当前文件语义候选为现有对象选项标记并稳定排序；复核详情始终计算只读候选，页面用原生 JavaScript 过滤现有 `<option>`。不新增接口、不引入前端依赖、不改变保存载荷。

**技术栈：** ThinkPHP 8、PHP 8.2、ThinkPHP 模板、Bootstrap 5、原生 JavaScript、现有 PHP smoke 测试。

---

## 文件结构

- 创建 `jewelry-qms/app/service/QmsTraceReviewOptionService.php`：纯函数完成候选 ID 映射、标记和稳定排序。

- 修改 `jewelry-qms/app/view/planning_structure/link_review.html`：增加零依赖搜索过滤、候选中文标识、动态结果提示和搜索框禁用联动。
- 创建 `jewelry-qms/tests/qms_trace_review_option_priority_smoke.php`：验证候选排序服务。
- 创建 `jewelry-qms/tests/qms_trace_review_search_runtime_smoke.php`：验证真实 8021 数据中的候选优先和记录要求块默认用途。
- 修改 `jewelry-qms/tests/qms_trace_relation_policy_ui_smoke.php`：验证搜索控件、候选标识、渐进增强和用途联动。

`blockTraceReviewDetail()` 始终以只读方式取得当前文件候选；调用：

```php
    self::traceReviewOptions(),

```
