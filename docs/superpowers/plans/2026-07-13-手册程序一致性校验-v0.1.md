**目标：** 在不修改生产数据库、受控文件和 `knowledge/internal/` 的前提下，建立一个可沿现有追溯关系校验手册要求与程序内容的只读命令，并用 5 份程序稳定复现 Y14、Y15、Y17、Y18 和 Y13 责任链候选。

**架构：** 手册试点要求以版本化 JSON 清单表达，并保留到手册 Markdown 的证据定位；纯规则服务负责极性、年限、版本规则、记录表和责任岗位判断，追溯服务只用 `SELECT` 读取当前块链接，报告服务输出 JSON/CSV/Markdown。测试使用固定 Markdown 和追溯快照，不连接生产库；真实试点才读取当前系统，并用运行前后文件哈希和数据表导出哈希证明零修改。

**技术栈：** PHP 8、ThinkPHP 8、MySQL 8（真实试点只读）、现有 PHP smoke 测试、Docker Compose、Markdown/JSON/CSV。

服务先只实现以下公开接口，所有路径规范化后验证位于显式输入目录，不自行寻找“第一份”手册或程序：

```php
final class QmsManualProcedureAlignmentService
{
    private const STATUSES = ['consistent', 'conflict', 'missing', 'review_required', 'not_applicable'];

    public static function loadInputs(string $specPath, string $procedureDir): array
    {
        $spec = self::readJson($specPath);
        self::assertSpec($spec);
        $manualPath = self::resolveInputPath(
            (string)$spec['manual']['path'],
            dirname($specPath),
            dirname(__DIR__, 3)
        );
        $manualText = self::readText($manualPath);
        $procedures = self::loadPilotProcedures($procedureDir, (array)$spec['pilot_procedures']);

        return $spec + [
            'manual' => $spec['manual'] + [
                'resolved_path' => $manualPath,
                'sha256' => hash('sha256', $manualText),
                'text' => $manualText,
                'lines' => self::locateManualSections($manualText, (array)$spec['requirements']),
            ],
            'procedures' => $procedures,
        ];
    }
}
```

`resolveInputPath()` 只按“绝对路径 → 试点 JSON 所在目录 → LIMS-zhj 仓库根目录”三处解析，匹配不唯一或均不存在即阻断。这样测试可引用同目录的 `manual-draft.md`，正式试点可引用仓库根下的 `knowledge/internal/`，同时避免扫描整台机器猜文件。

`assertSpec()` 必须拒绝：未知 schema、重复 finding ID、非 5 份试点程序、未知规则、缺少手册章节、目标不在试点清单、程序编号对应多个 Markdown、文件为空。

```php
private static function checkPolicyPolarity(array $requirement, array $procedure): array
{
    $action = (string)$requirement['action'];
    $matches = self::sentencesContaining((string)$procedure['text'], [$action, '手写', '改动', '划改']);
    $opposite = array_values(array_filter(
        $matches,
        static fn (array $row): bool => preg_match('/不允许|不得|禁止/u', $row['text']) === 1
    ));
    if ($opposite !== []) {
        return self::finding($requirement, $procedure, 'conflict', $opposite[0], [
            'polarity' => 'prohibit',
        ]);
    }
    return $matches === []
        ? self::finding($requirement, $procedure, 'missing')
        : self::finding($requirement, $procedure, 'consistent', $matches[0]);
}
```

不得把“不得擦涂”误判为“不得授权划改”；测试增加一个含“允许授权划改，但不得擦涂”的一致反例。

```php
public static function fromDatabase(array $manualSections, array $pilotProcedures): array
{
    $rows = Db::table('qms_document_blocks')
        ->alias('b')
        ->join('qms_structured_documents sd', 'sd.id = b.structured_document_id')
        ->join('qms_document_block_links l', 'l.block_id = b.id AND l.soft_delete = 0')
        ->join('documents d', 'd.id = l.procedure_document_id AND d.soft_delete = 0')
        ->where('sd.document_role', 'quality_manual')
        ->where('sd.doc_number', 'XZTC/SC')
        ->where('sd.source_status', 'current')
        ->whereIn('sd.status', ['structured', 'published'])
        ->where('sd.soft_delete', 0)
        ->where('b.soft_delete', 0)
        ->where('d.status', 'published')
        ->whereIn('d.doc_number', $pilotProcedures)
        ->field('b.section_number manual_section,b.id manual_block_id,l.relation_type,l.confidence,d.id procedure_document_id,d.doc_number procedure_number,d.version procedure_version')
        ->select()
        ->toArray();

    $elementIds = Db::table('qms_document_blocks')
        ->alias('b')
        ->join('qms_structured_documents sd', 'sd.id = b.structured_document_id')
        ->join('qms_document_block_links l', 'l.block_id = b.id AND l.soft_delete = 0')
        ->where('sd.document_role', 'quality_manual')
        ->where('sd.doc_number', 'XZTC/SC')
        ->where('sd.source_status', 'current')
        ->whereIn('sd.status', ['structured', 'published'])
        ->where('sd.soft_delete', 0)
        ->where('b.soft_delete', 0)
        ->whereNotNull('l.element_id')
        ->column('l.element_id');

    $elementRows = $elementIds === [] ? [] : Db::table('qms_element_documents')
        ->alias('ed')
        ->join('documents d', 'd.id = ed.document_id AND d.soft_delete = 0')
        ->whereIn('ed.element_id', array_values(array_unique($elementIds)))
        ->whereIn('d.doc_number', $pilotProcedures)
        ->where('d.status', 'published')
        ->where('ed.soft_delete', 0)
        ->field('ed.element_id,d.id procedure_document_id,d.doc_number procedure_number,d.version procedure_version')
        ->select()
        ->toArray();

    return self::groupByRequestedSection($rows, $manualSections, $elementRows);
}
```
