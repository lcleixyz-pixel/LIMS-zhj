## 北极星

让 jewelry-qms 从「默认 Bootstrap 老旧感」变成**专业稳重、权威可信**——检测机构给评审员/客户看的系统该有的样子。核心页先行见效，其他页靠全局 CSS 跟随。

## 风格规范（专业稳重）

### 配色（CSS 变量体系，便于以后一键调）

| 变量 | 值 | 用途 |
|---|---|---|
| `--qms-primary` | `#1e3a5f` 深蓝 | 顶栏/标题/主按钮 |
| `--qms-primary-2` | `#2c5282` | 链接/强调 |
| `--qms-ink` | `#2d3748` | 主文字 |
| `--qms-ink-2` | `#718096` | 次文字 |
| `--qms-bg` | `#f5f7fa` 浅灰 | 页面底 |
| `--qms-line` | `#e2e8f0` | 细边框 |
| `--qms-ok/warn/bad` | `#2f855a`/`#b7791f`/`#c53030` | 状态专用，克制 |

### 字体

`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。标题 600 粗，正文常规，基准 14px / 标题 19px / 次文字 12–13px。数字可加 `font-variant-numeric: tabular-nums`。

### 组件

- **顶栏**：深蓝 `#1e3a5f`，白字，高 54px，菜单项 `rgba(255,255,255,.78)`
- **card**：白底 + 细边框 `#e2e8f0` + 圆角 5px + 微阴影（比现在的 Bootstrap 阴影弱）
- **表格**：表头浅蓝灰 `#eef2f7`，行 hover `#f7fafc`，斑马纹弱化
- **按钮**：主按钮深蓝实心，次级白底描边，圆角 5px
- **badge**：浅底深字（绿 `#e6f4ec`/黄 `#fdf3e3`/红 `#fde8e8`），不抢眼

### 间距

页面留白比现在多（wrap padding 22–24px）；卡片间距 14–18px；表格行 padding 11–12px。

## 核心页清单（5 页先改）

1. **登录页**（第一印象）：深蓝顶栏 + 居中登录卡
2. **仪表盘 dashboard**（最常看）：统计卡区 + 本月待办表 + 快捷操作（原型已示）
3. **记录列表 record_form_instance/index**：表格 + 筛选 + 状态徽章
4. **记录填报 record_form_instance/create**：表单卡片化 + 字段分组 + 保存栏
5. **本月待办 calendar/index**（B3 刚做）：已接近原型，微调对齐

## 技术路径

- **继续 Bootstrap 5.3**（不换 Tailwind，成本太高、收益不抵风险）
- 主战场改 `public/static/css/qms.css`：
  - 定义 `:root { --qms-* }` 变量体系
  - 映射到 Bootstrap 变量（`--bs-primary` 等）让现有组件自动跟随
  - 全局组件样式（card/table/btn/badge 稳重化）
- 5 个核心页 view 微调：HTML 结构 + class 调整（**不动 PHP 逻辑/数据**）
- 非核心页：靠全局 qms.css 自动跟随，不单独改

## 工作量与顺序

2–3 会话。顺序：**qms.css 全局 → 登录 → 仪表盘 → 记录列表 → 记录填报 → 本月待办**。每页改完即可单独验收、立即见效。

## YAGNI（不做）

- 不换组件库（Bootstrap 够）
- 不做动画/过渡（稳重不需要花哨）
- 不改后端/数据/路由/PHP 逻辑
- 不改非核心页（靠全局 CSS 跟随，后续单独优化）
- 不做深色模式、不做响应式重做（保留现有响应式）

## 验收

每页改完：用户浏览器打开看效果 + 手机/平板瞥一眼（响应式没坏）。5 页都过 = UI 翻新核心页完成。非核心页优化进下一批。
