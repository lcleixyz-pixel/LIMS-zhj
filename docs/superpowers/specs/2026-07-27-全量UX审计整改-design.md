# 全量 UX 审计整改设计

**日期：** 2026-07-27  
**运行边界：** 仅增强代码并在 8021 治理试运行环境验证；不改动 8010，不把试运行数据视为正式体系证据。

## 1. 核实结论

对审计清单的 36 项逐项进行了代码、8021 HTTP、数据库和浏览器渲染交叉核对：

- 21 项需要整改，其中 `NEW-4` 是当前模板缓存暂未触发、但源文件已存在的潜在错误。
- 11 项已修复、清单过期或当前无法复现。
- 4 项不按原建议实施：不在启动时自动重置账号密码、不为解决死链扩大设备权限、不把通知读状态改为 GET 写操作、不为单个审计意见拆分顶层导航。

关键校准：

- 三个 SIM 账号当前环境密码与数据库哈希全部匹配；启动时静默改密会掩盖配置错误。
- `critical / major / minor` 三级合规严重度已经存在，8021 数据库分别有 3、10、3 条规则。
- `user_access` 当前未参与权限计算；资源菜单死链的根因是模块角色权限与岗位动作权限未统一。
- 培训详情已通过渲染脚本显示“原值删除线 + 当前值强调”，审计看到的相邻文本是 DOM 文本采集结果，不是实际视觉缺陷。

## 2. 设计原则

1. **权限不扩张：** 无权处理设备的人不再看到可点击死链，不通过追加角色权限绕过岗位任命。
2. **动作与结果一致：** 页面提供的入口必须能到达；不能到达时给出责任岗位和下一步。
3. **降级而非白页：** 数据表未迁移时显示可理解的初始化提示，不能出现 500。
4. **保留审计语义：** 更正申请人可查看自己的进度，审批人可查看并处理全部待办。
5. **轻量统一：** 保留 Bootstrap 管理界面和现有信息密度，只修文案、状态、空态和危险操作提示。

## 3. 实施范围

### 3.1 阻断项

- 新增 `equipment_period_checks` 幂等迁移，并为控制器增加缺表降级。
- 修复仪表盘图表初始化源文件中的重复变量和空态组件。
- 仪表盘、资源菜单、合规检查入口统一使用岗位动作权限。
- 将更正待办改为“更正申请中心”：审批岗位看全部待办和处理按钮；普通申请人只看本人申请及状态。
- 修复本人修改密码入口的路由遮蔽和 staff 角色权限拦截。

### 3.2 理解与一致性

- 培训类型中文化，空关联显示“未关联”。
- “已形成 PDF”改为“已生成（不可直接编辑）”。
- 内审计划、员工、用户、评审决议表头使用业务名词。
- 文件详情标题以文件标题为主、编号为辅。
- Copilot 模式改为“通用问答 / 当前页面问答 / 评审专家”。
- 登录环境提示改为 `role="status"`，支持通过配置显示支持联系人。
- 冻结状态增加锁定图标与更高可辨识度。
- 审计点名页面的空状态增加可执行下一步。
- 通用删除确认改为说明对象类型和不可撤销结果。

### 3.3 明确不做

- 不自动重置 SIM 密码；改用只读一致性检查作为验收证据。
- 不给 `sim_approver` 增加设备权限；隐藏或禁用无权入口。
- 不将通知“查看”改成会产生写入的 GET 请求。
- 不拆分顶层“资源管理”导航；现有分组标题继续保留。
- 不为“本月待办”添加含义不清的计数；顶部已有未读通知计数，待办口径需另行治理。

## 4. 数据与部署

- 迁移文件使用 `CREATE TABLE IF NOT EXISTS`，字段包括机构、设备、计划日期、状态、备注、审计字段和必要索引。
- 新建环境由治理 Compose 初始化挂载迁移。
- 现有 8021 数据卷通过显式命令应用该迁移，并在应用前后检查表结构。
- 不对 8010 容器、数据库或挂载执行迁移、重建或重启。

## 5. 验收

- 自动化：新增 UX 整改 smoke，覆盖迁移契约、权限入口、申请中心、中文化和可访问性文案。
- 静态：PHP 语法、`git diff --check`、相关既有 smoke 全部通过。
- 运行：在 8021 用 `sim_preparer / sim_reviewer / sim_approver` 验证导航、仪表盘、合规入口、更正中心和修改密码入口。
- 数据：期间核查页返回 200，可新增 SIM 计划；缺表防御通过独立测试验证。
- 边界：确认 8010 容器启动时间和状态未因本轮发生变化。
