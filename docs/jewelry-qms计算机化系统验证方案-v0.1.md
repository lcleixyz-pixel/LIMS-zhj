## 1. 目的与范围

证明 jewelry-qms 在投入使用前已经过功能确认，且持续满足 CL01 7.11 各项要求，经得起 CNAS 现场评审员就计算机化系统的询问。

**范围**：jewelry-qms 应用本身（含其 Docker 部署）。不含操作系统、网络、硬件等 IT 基础设施验证（那些由机构 IT 环境负责）。

## 2. 验证方法（三条线）

1. **功能确认**：78 个冒烟测试（`jewelry-qms/tests/*_smoke.php`），逐条映射到 7.11 要求——见第 4 节。
2. **演练确认**：备份恢复（A2）、权限矩阵（A3）等实操演练留痕。
3. **文档确认**：`QMS_OPERATIONS_RUNBOOK.md`（运维）、本验证方案、变更控制规定（A4）。

## 3. 系统描述

jewelry-qms 是基于 ThinkPHP 8 + MySQL 8 + Docker 的实验室质量管理系统，40+ 张数据表，覆盖受控发布、记录填报、内审、管评、CAPA、设备、培训等模块。部署形态：Docker Compose（app 容器内置 PHP+Node+Chromium，PDF 渲染自给自足）。冒烟测试为独立 PHP 脚本（非 PHPUnit），用自定义断言对源码/配置做静态校验或调 HTTP 端点。

CL01 7.11 当前证据结论为：**7.11.1、7.11.2、7.11.3 a–d、7.11.5、7.11.6 已有对应技术或运行证据；7.11.4 按机构自部署边界声明不适用；7.11.3 e 已建立应急制度，但尚缺系统失效桌面推演或等效演练证据，因此仅评为部分满足。** 完成演练并复核记录闭环后，才可形成完整的计算机化系统验证证据包。
